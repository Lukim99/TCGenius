# RPGenius 팝 모션그래픽 광고 「딱 한 판만…」 (90초)

- `RPGenius_pop_90s.mp4`: 1920×1080, 60fps, H.264 + AAC 48kHz, 90초
- `poster.jpg`: 썸네일/포스터 프레임

## 콘셉트

"오늘도 딱 한 판만 하고 자야지." 밤 11시 58분에 시작한 한 판이 아침 7시까지 이어지는 이야기입니다.
화면 오른쪽 위 작은 시계가 챕터마다 밤이 깊어지는 것을 보여 주고, 끝에서 알람이 울리면 캐릭터가 "…벌써 아침?!" 하고 놀랍니다.
마지막 CTA 버튼은 **"▶ 딱 한 판만 하기"**입니다.
첫 번째 영상(`output/promo`)의 어둡고 시네마틱한 골드 톤과 달리, 이번에는 밝은 네오팝 코믹 스타일로 만들었습니다.
원색 컬러 필드, 흰 테두리 스티커 컷아웃, 하프톤, 굵은 외곽선 타이포(게임 폰트 Black Han Sans), 의성어, 만화 컷 분할, 128 BPM에 맞춘 컷 전환이 특징입니다.

## 제작 방식

- 화면 캡처 없이 저장소의 게임 이미지 에셋(`DB/RPGenius/ui`, `cardImage`, `itemImage`, git 히스토리에서 복원)만으로 만들었습니다.
- 카드는 게임과 같은 방식으로 합성했습니다: 등급별 배경 + 캐릭터 일러스트 + 테두리. 조합 장면의 소용돌이는 게임의 실제 `조합-이펙트.gif`입니다.
- 모든 움직임은 시간 t의 순수 함수(HTML/CSS/JS)입니다. 헤드리스 크롬으로 프레임마다 렌더링했습니다.
  - 캐릭터: 숨쉬기(스쿼시·스트레치), 착지 반동, 대시·스핀의 컬러 잔상, 피격 플래시와 넉백, 흔들림
  - 연출: 카메라 펀치와 셰이크, 풀스크린 와이프(바·원·슬래시), 컨페티, 물리 기반으로 튀는 전리품
- 음악과 효과음은 numpy로 직접 합성한 오리지널입니다. 128 BPM, C장조, IV–V–iii–vi 진행을 씁니다. 로파이 인트로, 두 번의 드롭, 멈춤과 알람, 레코드 스크래치, 파이널 코러스로 구성했습니다. 타격·팝·코인·레벨업 등 효과음 272개가 화면과 같은 큐 시트로 맞물립니다.
- 실존 인물을 바탕으로 한 사실풍 캐릭터 스프라이트와 카드는 쓰지 않았습니다. 애니메이션풍 캐릭터(오버라이드, 봉인된 자물쇠 캐릭터)만 사용했습니다.

## 다시 만들기 (`src/`)

```bash
# 저장소 루트에서: 게임 이미지 에셋 복원(.gitignore 대상, git 인덱스는 건드리지 않음)
git archive 0206f3fd^ DB/RPGenius/cardImage DB/RPGenius/itemImage DB/RPGenius/ui | tar -x
cd output/promo2/src
./build.sh 4    # 에셋 준비 → 큐 시트 → 사운드 합성 → 5400프레임 렌더 → out/RPGenius_pop_90s.mp4
```

필요한 것: Node 18 이상(playwright, pretendard), Python 3(numpy, scipy, Pillow), ffmpeg.

## 게시 전 확인

- 주인공 캐릭터 '오버라이드'(붉은 드릴 트윈테일, 스킨명 '백만뷰'·'1억뷰')는 카사네 테토(重音テト)와 그 곡 「オーバーライド」를 모티프로 한 것으로 보입니다. 게임 밖 유료 광고로 집행하기 전에 해당 캐릭터의 이용 가이드라인과 권리 관계를 확인하세요. 다른 캐릭터로 바꾸려면 `src/prep_assets.py`의 캐릭터 이미지(`HERO`, 카드 합성 `COMPOSE`, 각성 표지)와 `src/ad/scenes.js`의 이름 텍스트(오버라이드/OVERRIDE)를 함께 교체하세요.
- 칭호 이미지 일부(2024올스타, DVA온라인 등)는 커뮤니티 이벤트 이름입니다. 외부 광고에서는 필요하면 교체하세요.
