# E세계대저택 레이드 홍보영상

- `E세계대저택_레이드_홍보영상.mp4`: 1920×1080 · 30fps · 50초 · AAC 스테레오(-14 LUFS)
- `thumbnail.jpg`: 대표 이미지(위플래쉬 : 잔향)

## 제작 방식

모든 전투 장면은 실제 게임 화면입니다. `server.js`·`partyquest.js`·`mansion_raid.js`를 그대로 띄우고 하드 난이도를 4인 파티로 끝까지 클리어하며 녹화했습니다.

1. `director.js`: 실제 서버를 메모리 DB로 격리해 띄웁니다. 운영 DynamoDB와 S3에는 쓰지 않습니다. 봇 파티원 3명이 실제 공격·스킬 함수를 호출합니다. 연출 순서에 맞추려고 일반 패턴의 발동 시점, 체력 기믹 진입 체력, 파티원 HP 보정만 조절합니다. 패턴 판정과 이펙트는 엔진과 클라이언트 그대로입니다.
2. `record.js`: Chromium에서 `/party`를 열고 CDP 스크린캐스트로 프레임과 시각을 저장합니다. 축복 수락, 기둥 이동, 눈뜬 장님, 완성, 맥동 선택 같은 입력은 실제 UI를 클릭해 진행합니다. 프레임을 창 전체로 넓혀 전투 무대가 16:9에 가깝게 나오도록 촬영했습니다.
3. `edit/comp.html` + `edit/render.js`: Canvas 합성기로 프레임 단위 렌더링을 합니다(크롭·카메라 이동·전환·자막·컷인·색보정·그레인).
4. `edit/audio.py`: 레이드 BGM(1관문→2관문)과 레이드 효과음 샘플을 영상 타이밍에 맞춰 믹스합니다.

패턴 노출은 일부러 줄였습니다. 이펙트와 공식 대사만 보여 주고, 기둥과 축복의 입력 패널은 화면 가장자리에서 잘리게 했습니다. 정답, 성공 조건, 받아쓰기 순서는 보여 주지 않습니다.

재제작: `node director.js` → `node record.js <rec>` → `edit/`에 녹화 결과(`frames`, `index.json`)와 폰트·원화를 배치 → `node render.js <out>` → `python3 audio.py mix.wav` → ffmpeg 인코딩
