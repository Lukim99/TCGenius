# 루킴의 생일파티

`lukimBirthday2026`은 한국 시간 2026년 10월 6일 00:00부터 10월 7일 00:00 전까지 입장할 수 있는 이벤트 레이드다. 레벨과 해금 조건 없이 1~4명이 참가한다. 날짜 검사는 목록, 생성, 참가, 시작과 재시작에 적용한다. 이미 진행 중인 전투는 자정이 지나도 마칠 수 있다.

## 공통 엔진

전투와 보상 화면은 기존 `partyquest.js`, `public/party.js`를 사용한다. `birthday_raid.js`는 이벤트의 판정과 상태만 관리한다. 기본 공격, 스킬, 연격, 지속 피해와 소환 공격은 기존 공통 계산기를 통과하며, 이 보스의 실제 양수 타격만 각각 1 피해로 변환한다. 514와 1의 체력 하한을 넘은 타격은 피해 표시와 통계에서도 제외한다.

피해, 회복, 보호막, 물약 사용, 3초 관문 컷씬, 전멸 연출과 결과 로그는 [공통 연출 기준](raid-presentation.md)을 따른다. 카운트다운과 일반 전투 효과음도 기존 설정을 유지한다.

## 1관문

- 촛불은 6개다. 성냥은 첫 촛불에 3초째 도달하고, 이후 3초 간격으로 다음 촛불을 지난다. 각 촛불의 1.5초 판정 구간 동안 생존자 전원이 일반 공격을 한 번씩 입력해야 한다. 공격 쿨타임은 기존 규칙을 사용한다.
- 판정 구간의 숫자, 성공 영역과 대응 설명은 표시하지 않는다. 성냥 위치와 실제로 붙은 촛불이 신호다. 촛불은 전원이 공격한 순간 점화하고, 한 명이라도 빠지면 성냥 통과 후 전멸한다. 스킬은 사용할 수 없다.
- 여섯 촛불을 모두 붙이면 루킴이 1.4초 동안 불어 끈다. 이후 2.5초 안에 생존자 전원이 박수 버튼을 눌러야 한다. 서버 마감 이후 입력과 중복 입력은 성공 횟수를 늘리지 않는다.
- 박수 성공 뒤 0.8초 축하 동작을 마치고 공통 관문 컷씬을 거쳐 2관문으로 넘어간다. 케이크 투척으로 전투를 시작한다.

## 2관문

| 조건 | 동작 |
| --- | --- |
| 체력 1006 | 각 실제 타격마다 1씩 감소. 연격, 다단 스킬, 화상과 소환 공격도 같은 기준 |
| 3초 간격 | 파티 전원에게 최대 체력의 2.5% 피해를 주는 케이크 투척 |
| 27초 간격 | 무작위 생존자를 2초 동안 물색하고 휴대 물약 한 병을 탈취해 1초 동안 마심. 물약이 없으면 전멸 |
| 70초 간격 | 5초 동안 행동을 멈추고 코딩. 이어서 15초 동안 캐릭터와 일반/전직/각성 형태를 매초 무작위로 변경 |
| 체력 514 | 체력을 514에서 10초 동안 고정. 0.5초마다 무작위 생존자에게 10~10000 피해 |
| 체력 1 | 체력을 1에서 10초 동안 고정. “오늘은 내 생일!” 말풍선과 선물 패널 표시. 생존자 전원이 휴대 물약 한 병씩 제출하지 않으면 전멸 |

코딩의 5초 동안 케이크와 탈취 타이머도 멈춘다. 514과 선물 구간에서는 주기 패턴을 계속 진행한다. 코딩은 진행 중인 514 또는 선물 구간을 끊고 시작하지 않는다. 15초 카드 변경이 끝나 원래 카드로 돌아온 뒤 다음 70초를 센다.

카드 변경은 방 안의 카드 표시와 사용 가능한 메인 카드 스킬에만 적용한다. 원래 성급, 전투 스탯, 장비 스킬, 쿨타임과 계정 소유 카드는 유지한다. 스냅샷을 받으면 카드와 스킬 버튼을 함께 갱신한다. 종료 또는 실패 시에도 원래 카드와 스킬로 복원한다.

탈취와 선물은 전투 시작 때 실제로 휴대한 수량만 소모한다. 선물은 패턴 식별자와 계정으로 중복 제출을 막고, 종료 시 남은 휴대 물약만 환불한다. 탈취한 물약의 효과를 플레이어나 보스에게 적용하지 않는다.

## 보상과 운영 데이터

계정마다 한 번 아래 보상을 지급한다. 아이템은 현재 운영 정의를 사용하고, 레전더리 아티팩트는 기존 생성 기능으로 중복 없는 옵션 3개를 뽑아 지급한다.

- 루킴의 축복 사용권 (30일) 1개
- 레전더리 아티팩트 1개
- 가넷 1006개
- 9성 카드팩 1개
- 케이크 10개
- 고급 장비 보호권 3개
- 럭키카드30% 1개

케이크는 등록 시점의 운영 엘릭서 기능을 복사한다. 기존 케이크가 있다면 그대로 사용한다.

수령 여부는 `titleProgress.lukimBirthday2026Reward`에 저장한다. 남은 물약 환불이 끝난 뒤 인벤토리, 가넷, 수령 기록과 퀘스트 진행을 조건부 저장으로 함께 반영한다. 저장 충돌 시 보상과 수령 기록을 함께 복구하고 결과에 지급 실패를 표시한다. 다시 클리어한 계정에 보상을 중복 지급하지 않는다.

`scripts/init_birthday_content.js`는 직접 실행할 때만 운영 Item의 누락 항목을 추가한다. 기본 실행은 읽기만 하며, 실제 등록은 `--apply --backup-dir <경로>`를 사용한다. 기존 설정의 백업, 동시 수정 검사와 저장 후 일치 검사를 수행한다. 서버 시작과 테스트에서 운영 데이터를 수정하지 않는다.

## 연출

Claude Opus 5.5에 실제 보스와 연회장 이미지를 제공해 소품 동선, 광원, 모바일 구성과 효과음 방향을 위임했다. 그 결과에 따라 내장 imagegen의 실제 소품과 동작 스프라이트를 Canvas에 합성한다. 구현은 `public/birthday-raid.js`에 있고 판정은 서버가 결정한다.

- 성냥의 불씨, 촛불 점화와 소화 연기는 케이크 위의 실제 심지를 따라간다.
- 케이크는 내민 손에서 포물선을 따라 파티 초상으로 날아간다. 크림이 충돌한 뒤 작은 덩어리가 중력 방향으로 흐른다.
- 탈취는 지정 대상 초상을 강조하고 실제 휴대 물약 이미지가 입으로 이동한다.
- 코딩은 손이 키보드에 놓인 전용 보스 이미지와 낮은 화면광, 외부 타자 녹음으로 표현한다. 얼굴을 가리는 별도 노트북 합성은 사용하지 않는다.
- 카드 교체는 원래 초상에서 새 초상으로 뒤집는다. 새 그림의 디코딩이 끝날 때까지 이전 그림을 유지한다.
- 514은 붉은 주변 암부와 피해 크기에 따른 무대 흔들림으로 표현한다. 입력 버튼과 파티 배치는 움직이지 않는다.
- 선물은 이미지 버튼과 보스 앞의 실제 쟁반으로 표시하고, 제출한 물약이 초상에서 쟁반으로 이동한다. 말풍선은 원본 입 좌표를 `contain` 배치로 변환해 얼굴 오른쪽에 놓고 꼬리로 입을 가리킨다. 눈과 입을 덮지 않는다.

박수와 선물만 공통 패턴 입력 패널을 사용한다. 나머지 동작은 시각 효과로 표시해 같은 문구를 반복하지 않는다. 재접속은 현재 사건의 남은 구간부터 이어가고, 방 이동, 관문 전환과 결과에서는 프레임, 숨김 이미지와 음원을 정리한다. 동작 줄이기 설정에서는 빠른 이동, 카드 뒤집기와 강한 흔들림을 생략한다. 에셋과 음원 출처는 [제작 기록](lukim-birthday-assets.md)에 있다.

1관문은 `sfx/lukim-birthday-phase1-v1.mp3`, 2관문은 사용자가 제공한 `sfx/lukim-birthday-phase2.mp3`를 사용한다. 관문 전환 때 공통 음악 계층의 1.5초 교차 재생을 적용한다.

## 검증

`tests/mansion_raid.test.js`, `tests/party_music.test.js`, `tests/web_game_actions.test.js`에서 날짜와 낮은 레벨 입장, 협동 입력, 피해 하한, 실제 물약 소비와 환불, 카드 복원, 보상 중복 및 저장 충돌을 운영 DB 쓰기 없이 검사한다. 실제 브라우저에서는 1280px PC와 360px 모바일의 무대, 코딩 동작, 선물 제출, 말풍선, 초상 이미지와 실시간 스킬 갱신을 확인했다. 보상 화면의 7종 아이콘과 수량이 모두 정상 표시됐으며 브라우저 오류와 가로 넘침이 없었다.
