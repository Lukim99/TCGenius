# 암시장

상점 첫 탭의 핫딜샵 자리를 암시장으로 대체한다. 기존 핫딜 구매 API는 중단 상태를 유지하며 기존 상품·구매 기록은 수정하지 않는다. 팝니다/삽니다의 계정별 20건 등록 제한은 제거한다.

- 한국 시간 00:00부터 23:50 직전까지 입찰·변경·취소할 수 있다. 23:50부터 자정까지는 정산 시간이다.
- 매일 카드–가넷, 카드–골드, 아이템–가넷, 아이템–골드의 네 매물이 등장한다. 카드는 실제 존재하는 일반·전직·각성 캐릭터의 5~9성 중에서 뽑는다.
- 입찰가는 본인에게만 보인다. 최고 금액, 타인 입찰, 참가자 수를 클라이언트에 보내지 않는다.
- 입찰금은 즉시 보관한다. 금액 변경은 차액만 정산하고 취소·유찰은 전액 반환한다. 동액은 해당 금액을 먼저 제출한 순서로 결정한다. 같은 금액 재요청은 순서를 바꾸지 않는다.
- 낙찰자는 본인의 입찰금으로 결제한다. 낙찰품은 기존 메일함으로 지급한다. 지난 결과에는 매물, 낙찰자와 낙찰가가 표시된다.
- 관리자 암시장 탭에서 당일 입찰 시작 전 매물 또는 미래 날짜 매물을 지정할 수 있다. 한번 입찰이 시작된 매물은 전원 취소하더라도 교체하지 않는다.

## 저장과 정산

`rpgenius_data`의 전용 `BlackMarket` 레코드에 현재 날짜·매물·입찰·정산 단계·직전 결과·미래 지정 매물을 저장한다. 운영 카탈로그를 서버 시작 시 초기화하거나 덮어쓰지 않는다. 아이템 이름은 운영 `Item` 데이터에서 찾아 ID를 결정한다.

보관금 차감·반환과 입찰 상태, 낙찰 보상 메일과 처리 완료 상태는 DynamoDB 조건부 트랜잭션으로 함께 저장한다. 각 입찰 처리 후 미처리 목록에서 제거하므로 오류나 재시작 후에도 완료한 지급/반환을 반복하지 않는다. 낙찰 메일 수령도 인벤토리와 수령 상태를 함께 조건부 저장한다. 사용자 작업은 기존 계정별 큐를 사용한다.

서버는 30초 간격으로 정산을 확인한다. 암시장 조회 시에도 누락된 정산을 이어 처리한다. 중단된 기간의 미정산 입찰부터 끝내고 현재 날짜로 전환하며, 서버가 꺼져 있던 날짜의 가상 입찰은 만들지 않는다. 여러 서버의 동시 변경은 저장 조건으로 충돌을 감지하고 요청자는 새로고침 후 재시도한다.

현재 방식은 기존 거래 데이터처럼 단일 DynamoDB 항목을 사용한다. 동시 입찰자가 크게 늘어 항목 크기 한도(400KB)에 접근하면 입찰 저장소 분리가 필요하다. 한도 초과 시 트랜잭션 전체가 실패하므로 입찰금만 차감되지는 않는다.

## 신규 아이템

`node scripts/init_black_market_items.js`는 누락된 제타·시그마 각성 캐릭터 변환석을 조회한다. `--apply`를 명시한 경우에만 운영 목록 끝에 추가하고 기존 정의·인덱스는 보존한다. 제타는 제타 이하, 시그마는 시그마 이하 각성 카드에 사용할 수 있다. 두 신규 아이템 모두 기존 각성 캐릭터 변환석 이미지를 사용한다. 기존 일반 각성 변환석의 동작은 유지한다.

## 검증

`node --test tests/black_market.test.js tests/awakening.test.js tests/web_game_actions.test.js tests/shop_identity.test.js`

테스트는 SDK 경계에서 DB를 메모리로 대체하며 운영 DB와 환경 파일을 사용하지 않는다. 인증, 비공개 응답, 관리자 지정, 보관금 변경과 취소, 동시 요청, DB 실패/응답 유실, 동액 우선순위, 마감/자정 경계, 중단 정산 재개, 보상 수령 및 21번째 거래 등록을 확인한다.

`BLACK_MARKET_BROWSER=1` 환경 변수로 같은 테스트의 Playwright 브라우저 검사도 실행한다. Playwright 패키지와 Microsoft Edge가 필요하며, 실제 상점·암시장 API를 격리 DB와 연결한다. 화면 기록은 `output/black-market/`에 저장한다.

배경과 봉인 이미지는 ImageGen으로 생성했고 효과음은 Kenney RPG Audio(CC0)를 사용한다. 생성 프롬프트와 출처는 `public/assets/black-market/CREDITS.md`에 기록한다.
