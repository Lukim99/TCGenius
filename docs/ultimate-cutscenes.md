# 캐릭터 궁극기 컷씬

사용자가 제공한 `궁극기 컷씬/궁극기 컷씬`의 17개 WebP 원본을 그대로 사용한다. 모두 1280×520, 1회 재생이며 1,799~2,399ms이다. `public/ultimate-cutscene.js`는 캐릭터별 전직 궁극기와 스펙터의 빅뱅을 연결한다. 각성 카드와 스킨도 카드 본명을 기준으로 같은 연출을 사용한다.

- 일반·헬 필드, 일일 던전, 훈련장, 천상·지옥은 공통 `hfield.js`의 실제 시전 사건에서 재생한다. 천상의 거울 적도 같은 경로를 사용한다.
- 월드보스와 PVP는 성공한 전투 사건에서 재생한다. 소환 공격·지속 피해·실패한 시전에는 재생하지 않는다.
- 레이드는 사용 검증과 MP·쿨타임 처리가 끝난 뒤 `skill-cast` SSE를 파티원과 관전자에게 전달한다. 사건 ID, 방·전투·관문, 시전자와 카드 본명을 포함하며 재접속 스냅샷에는 저장하지 않는다. 공격 피해가 없는 소환·강화 궁극기도 전달한다.
- 준비 시 보유한 궁극기 파일만 읽는다. Blob은 재사용하고 시전마다 새로운 Object URL을 만들어 1회 재생 애니메이션을 처음부터 시작한다. 동시 시전은 순서대로 재생한다.
- 전투 무대의 비율을 유지한 투명 띠로 표시한다. 입력을 가로채거나 전투·HP 갱신을 멈추지 않는다. 레이드의 패턴 입력과 관문 전환은 기존 공통 연출 규칙을 유지한다.
- 화면 이동·관문 변경·탭 숨김에서는 대기 중인 연출과 Object URL을 정리한다. 사건 ID 중복과 2.5초 넘게 지연된 사건은 다시 재생하지 않는다. 동작 줄이기 설정에서는 원본의 정지 프레임을 1초간 표시한다.

S3 경로는 `tcgenius/assets/ui/궁극기/<캐릭터>-v1.webp`와 `<캐릭터>-still-v1.webp`이다. 기존 `asset_store.js` 동기화와 인증된 `/rpg-ui` 경로를 사용한다. SHA-256 목록은 `scripts/ultimate_cutscene_assets.json`이며 명시적인 `scripts/migrate_ultimate_cutscene_assets_to_s3.js --apply`로 누락된 파일만 등록한다. 파일명이 같은 다른 내용을 덮어쓰거나 운영 데이터를 수정하지 않는다.

`tests/ultimate_cutscene.test.js`는 전체 캐릭터 연결·재생 길이·버프/소환·중복 제거·탭 숨김·늦은 로딩·재시전 초기화·동작 줄이기를 검증한다. `tests/mansion_raid.test.js`는 실제 사용 검증과 파티원·관전자 SSE를 운영 DB 쓰기 없이 확인한다.
