# 상점 화면 디자인

## 방향

일반 상점 화면을 Claude CLI `claude-opus-5-5`에 시각 디자인을 위임해 구현했다. `public/shop-painter.js`가 Canvas2D로 그리고,
`public/shop-scene.js`가 그 캔버스를 WebGL 텍스처로 올려 조명과 입자를 합성한다. HTML로 만든 시각 카드는 없다. 버튼은 렌더러가 `A.hit`로 받은
사각형에 보이지 않는 접근성 버튼을 겹친다.

- 주인공은 상품 그림, 이름, 가격, 구매 버튼, 보유 재화다. 설명 문구, 장식 문구, 영어 라벨, 가운뎃점은 쓰지 않는다.
- 낙원 상점(`paradise-shop.js`)은 만듦새만 참고한다. 돌 재질, 신전 구도, 원형 인장은 쓰지 않는다.
- 재질: 왼쪽 위와 오른쪽 아래를 깊게 깎은 각진 판, 강철 그라디언트 테두리와 안쪽 검은 선(베벨), 반투명 바탕.
  배경 전체를 덮지 않는다. 뒤의 WebGL 조명이 판 사이로 보인다.
- 카테고리 색: 탭 이름으로 정하는 강조색 하나. 무대 조명, 선택 발광, 받침 테두리, 레일 표식에만 쓴다.
- 구매 버튼은 어느 탭에서든 같은 금색.
- 글꼴: Pretendard. 모든 이름은 전체를 표시한다. 줄바꿈하고, 상자에 안 들어가면 글자 크기를 줄인다. 말줄임 없음.

## 구성

| 화면 | 구성 |
| --- | --- |
| 데스크톱 (1200 이상) | 위: '상점' 표지와 재화. 왼쪽: 분류 세로 레일(48px 버튼, 넘치면 마지막 칸이 '전체 분류'). 가운데: 큰 무대(위 상품 그림, 아래 왼쪽 이름·가격·제한, 아래 오른쪽 수량·영수증·구매). 오른쪽: 인벤토리 슬롯판 |
| 태블릿 (640-1199, 장면 높이 780 이상) | 위: 표지와 재화. 분류 선택 버튼. 가로 무대(왼쪽 그림, 오른쪽 정보와 구매). 아래 인벤토리 |
| 모바일 목록 (640 미만) | 분류 선택 버튼, 재화 한 줄, 재료 선택 버튼(있을 때), 2열 슬롯, 페이지 버튼 |
| 모바일 상세 (`mode: detail`) | 목록을 대신한다. 뒤로 버튼, 무대, 이름·가격·제한, 수량·영수증·구매 |

슬롯 수는 페인터가 화면 크기로 정해 `s.perPage`에 쓰고 `s.page`를 범위 안으로 맞춘다.
빈 칸은 빈 소켓으로 그려 인벤토리 판 모양을 유지한다.
높이가 짧은 태블릿은 모바일처럼 목록과 상세 화면을 나누고, 목록 열 수는 폭에 맞춘다.
암시장은 기존 WebGL 화면을 유지하고 공통 상점 너비와 분류 탐색, 지난 결과 표시를 수정한다.

## 무대

- 분류색 역광, 위에서 내려오는 광선 다섯 줄, 원근 바닥 격자.
- 육각 받침(옆면은 강철, 윗면 테두리는 분류색), 받침 둘레를 반대로 도는 납작한 사각 테 두 겹, 떠오르는 불씨.
- 상품 그림은 받침 위에 크게, 천천히 떠 있다. 받침 윗면에 흐린 반사.
- 품절과 보유중은 그림을 흑백 반투명으로 그리고 상태 표를 붙인다.
- `A.reduced`이면 시간을 0으로 고정한다(정지 화면).

## 슬롯

강철 판 안에 분류색으로 은은히 밝힌 소켓, 모서리 리벳, 그 위에 그림. 아래에 이름(전체), 맨 아래 가격.
선택: 분류색 발광, 2px 테두리, 맥동하는 모서리 브래킷. 호버: 테두리가 밝아지고 그림이 2px 뜬다.

## 구매

- 수량: 줄이기, 직접 입력 가능한 현재값(아래 '최대 N'), 늘리기, '최대'. 높이 44px.
- 영수증: 보유 / 비용 / 구매 후, 각각 재화 아이콘. 구매 후가 음수면 붉은색.
- 구매 가능 수량이 0이면 구매 버튼이 비활성이고 이유(품절, 보유중, 재화 부족, 구매 불가)를 버튼에 쓴다.
- 구매 버튼은 확인 창을 연다. 확인 창에 이름 전체, 수량, 영수증, 취소와 구매가 있다. 진행 중이면 '구매 중'.

## 겹창

반투명 어두운 막 위에 각진 판. 겹창이 떠 있으면 아래 화면 버튼은 등록하지 않는다.

| 모드 | 내용 | 닫기 |
| --- | --- | --- |
| `confirm` | 구매 확인 | `cancel` |
| `success` | 회전하는 빛줄기, 상품 이름과 수량, 보상 목록 | `success-close` |
| `contents` | 구성품 목록(그림, 이름, 수량 및 범위, 라벨) | `back` |
| `categories` | 분류 버튼 격자 | `back` |
| `materials` | 재료 버튼 격자 | `back` |
| `s.message` | 알림 문구(줄바꿈) | `back` |

구성품과 보상 목록은 `s.detailPage`로 넘기고 페인터가 `s.detailPages`를 쓴다. 둘 다 `content-previous`, `content-next`를 쓴다.

## 페인터 계약

`window.ShopPainter.draw(A)`. 매 프레임 캔버스를 지우고 다시 그린다.

- 읽는 것: `A.ctx, w, h, t, reduced, s, items, item, max, balance, limits, art, currency, hit`.
- 쓰는 것: `s.perPage`, `s.page`(범위 보정), `s.detailPages`, `s.detailPage`(범위 보정). `s.qty`는 쓰지 않고 표시만 1..최대로 맞춘다.
- 재료 목록: `A.materials`(문자열 배열)가 있으면 그것을 쓰고, 없으면 `s.data.shop`과 `A.items`의 `materialTab`에서 모은다.
- 탭은 문자열 또는 `{ id, name }`, 재화는 `{ gold: n }` 객체 또는 `[{ goods, amount }]` 배열을 받는다.
