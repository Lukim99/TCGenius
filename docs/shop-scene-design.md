# 상점 화면 디자인

## 방향

일반 상점 화면을 Claude CLI `claude-opus-5-5`에 시각 디자인을 위임해 구현했다. `public/shop-painter.js`가 Canvas2D로 그리고,
`public/shop-scene.js`가 그 캔버스를 WebGL 텍스처로 합성한다. HTML로 만든 시각 카드는 없다. 버튼은 렌더러가 `A.hit`로 받은
사각형에 보이지 않는 접근성 버튼을 겹친다.

- 주인공은 상품 그림, 이름, 가격, 구매 버튼, 보유 재화다. 설명 문구, 장식 문구, 영어 라벨, 가운뎃점은 쓰지 않는다.
- 낙원 상점(`paradise-shop.js`)은 만듦새만 참고한다. 돌 재질, 신전 구도, 원형 인장은 쓰지 않는다.
- 재질: 왼쪽 위와 오른쪽 아래를 깊게 깎은 각진 판, 강철 그라디언트 테두리와 안쪽 검은 선(베벨), 반투명 바탕.
  배경 전체를 덮지 않는다. 생성한 정적 배경이 판 사이로 보인다.
- 카테고리 색: 탭 이름으로 정하는 강조색 하나. 선택 테두리와 판의 은은한 색, 레일 표식에만 쓴다.
- 구매 버튼은 어느 탭에서든 같은 금색.
- 글꼴: Pretendard. 모든 이름은 전체를 표시한다. 줄바꿈하고, 상자에 안 들어가면 글자 크기를 줄인다. 말줄임 없음.

## 구성

| 화면 | 구성 |
| --- | --- |
| 데스크톱 (1200 이상) | 위: '상점' 표지와 재화. 왼쪽: 분류 세로 레일(48px 버튼, 넘치면 마지막 칸이 '전체 분류'). 가운데: 큰 무대(위 상품 그림, 아래 왼쪽 이름·가격·제한, 아래 오른쪽 수량·영수증·구매). 오른쪽: 인벤토리 슬롯판 |
| 태블릿 (640-1199, 장면 높이 780 이상) | 위: 표지와 재화. 분류 선택 버튼. 가로 무대(왼쪽 그림, 오른쪽 정보와 구매). 아래 인벤토리 |
| 모바일 목록 (640 미만) | 분류 선택 버튼, 금액 길이에 맞춘 재화 판, 재료 선택 버튼(있을 때), 2열 슬롯, 페이지 버튼 |
| 모바일 상세 (`mode: detail`) | 목록을 대신한다. 뒤로 버튼, 무대, 이름·가격·제한, 수량·영수증·구매 |

슬롯 수는 페인터가 화면 크기로 정해 `s.perPage`에 쓰고 `s.page`를 범위 안으로 맞춘다.
빈 칸은 빈 소켓으로 그려 인벤토리 판 모양을 유지한다.
높이가 짧은 태블릿은 모바일처럼 목록과 상세 화면을 나누고, 목록 열 수는 폭에 맞춘다.
암시장도 같은 페인터의 분기로 그린다(아래 '암시장').

## 재화 숫자

- 재화와 금액은 항상 전체 숫자를 쉼표로 표시한다. 줄임 표기, 말줄임, 잘라내기 없음. 숫자 글자는 12px 아래로 줄이지 않는다.
- 재화 판 묶음(`purses`): 숫자 폭을 재서 모든 판이 한 줄에 들어가면 한 줄, 아니면 2열, 2열 칸에도 안 들어가는 값은 한 줄 전체를 쓴다.
  모바일은 큰 골드에서 한 줄이 더 생긴다. 데스크톱과 태블릿 상단은 자연 폭이 안 들어갈 때만 같은 묶음으로 바꾸고 아래 판이 그만큼 내려간다.
- 영수증: 세 칸에 숫자가 들어가면 가로, 아니면 이름표와 금액 줄로 쌓는다(`ledger`). 금액이 이름표 옆에 안 들어가면 다음 줄로 내린다.
  구매 영역, 상세 화면, 구매 확인 창 높이가 여기에 맞춰 늘어난다.
- 큰 금액 검증 기준: 10,268,277,770 / 99,999,999,999,999 / 9,007,199,254,740,991(`Number.MAX_SAFE_INTEGER`), 360px 폭.

## 배경과 슬롯

- 일반 상점에는 ImageGen으로 만든 어두운 무광 재질의 정적 배경을 사용한다. 암시장은 기존 vault.webp 배경과 seal.webp 봉인 이미지를 그대로 사용한다.
- 상품 그림을 단순한 전시 영역 가운데 크게 표시한다.
- 일반 상점은 선택 시 테두리만 바뀐다. 퍼지는 빛, 회전 받침대, 입자와 구매 완료 반짝임을 사용하지 않는다.
- 품절과 보유중은 그림을 흑백 반투명으로 그리고 상태 표를 붙인다.
- 일반 상점은 화면 변화와 이미지 로딩 때만 다시 그린다. 암시장은 기존 안개와 입자를 초당 최대 25회 갱신하며, 화면이 가려지거나 모션 감소 설정을 켜면 반복 렌더링을 멈춘다.

## 구매

- 수량: 줄이기, 직접 입력 가능한 현재값(아래 '최대 N'), 늘리기, '최대'. 높이 44px.
- 영수증: 보유 / 비용 / 구매 후, 각각 재화 아이콘. 구매 후가 음수면 붉은색.
- 구매 가능 수량이 0이면 구매 버튼이 비활성이고 이유(품절, 보유중, 재화 부족, 구매 불가)를 버튼에 쓴다.
- 구매 버튼은 확인 창을 연다. 확인 창에 이름 전체, 수량, 영수증, 취소와 구매가 있다. 진행 중이면 '구매 중'.

## 겹창

반투명 어두운 막 위에 각진 판. 겹창이 떠 있으면 아래 화면 버튼은 등록하지 않는다.

| 모드 | 내용 | 닫기 |
| --- | --- | --- |
| `confirm` | 구매 확인 | `cancel` |
| `success` | 상품 이름과 수량, 보상 목록 | `success-close` |
| `contents` | 구성품 목록(그림, 이름, 수량 및 범위, 라벨) | `back` |
| `categories` | 분류 버튼 격자 | `back` |
| `materials` | 재료 버튼 격자 | `back` |
| `s.message` | 알림 문구(줄바꿈) | `back` |

구성품과 보상 목록은 `s.detailPage`로 넘기고 페인터가 `s.detailPages`를 쓴다. 둘 다 `content-previous`, `content-next`를 쓴다.

## 암시장

`s.market`이 있으면 상품 영역 대신 암시장을 그린다. 상단 표지와 재화, 데스크톱 레일, 태블릿과 모바일의 분류 선택 버튼, 분류 겹창은 그대로다.
강조색은 보라 `#a98bff`. 재화 색과 전시 조명은 기존 암시장의 골드 `#f1c463`, 가넷 `#b98aff`를 쓴다. 입찰 버튼은 구매 버튼과 같은 금색.

| 화면 | 구성 |
| --- | --- |
| 데스크톱 | 큰 판 하나. 머리: '암시장' 표지, 가운데 상태와 남은 시간과 마감 시각, 오른쪽 '지난 결과', '거래 규칙', 새로고침, 우편함. 가운데: 왼쪽 두 칸 '오늘의 카드', 오른쪽 두 칸 '오늘의 아이템'. 아래: 선택 물품 입찰대(그림, 이름, 보유 재화와 내 보관금, 금액 칸, 입찰 취소, 입찰하기) |
| 태블릿 | 같은 판. 구역은 2x2(카드 줄, 아이템 줄), 입찰대는 정보 줄 아래 입력 줄 |
| 모바일 목록 | 분류 선택, 가넷과 골드 보유량, 상태와 시계 띠와 새로고침과 우편함, 2x2 선택판, '지난 결과'와 '거래 규칙' |
| 모바일 상세 (`market.mode: detail`) | 뒤로, 상태와 시계, 무대, 이름 전체, 보유 재화와 내 보관금, 금액 칸, 입찰 취소와 입찰하기 |

구역 칸: 종류(카드, 아이템), 재화 아이콘과 이름, 전시 그림(`A.art`), 이름 전체, 내 보관금 또는 '미입찰'. 선택은 일반 슬롯과 같은 테두리와 브래킷.
암시장의 기존 연출을 공통 렌더러 안에서 유지한다. 기존 WebGL 안개와 24개 입자는 UI 뒤에서 움직인다. 청동 받침대는 회전하지 않고, 빛은 아래의 좁은 밑면에서 위로 넓어진다. 카드 원화의 테두리는 유지하고 아이템에는 장비 프레임을 덧씌우지 않는다. 마우스를 올리면 그림이 살짝 올라간다. 입찰 완료에는 기존 확대와 테두리 빛, 받침대 밝기 변화가 적용된다. 확인 창의 봉인 이미지도 기존 도장 동작으로 등장하며, 정산 때는 매물 위에 봉인이 표시된다.
다른 사람의 입찰은 그리지 않는다. 금액 칸은 `drafts[sector]`를 쉼표로 표시하고 실제 입력은 부모가 같은 사각형에 겹친다.

| 겹창 | 내용 | 닫기 |
| --- | --- | --- |
| `market.message` | 성공은 매물 연출을 가리지 않는 하단 알림, 오류는 확인 창에 붉은 글씨 | `market-back` |
| `market.dialog` | 입찰 확인 또는 입찰 취소 확인: 그림, 이름, 재화, 현재 보관금, 변경 후 입찰금, 추가로 맡길 금액 또는 즉시 돌려받을 금액, 변경 후 보유 재화, 보관과 동점 안내 | `market-back` ('돌아가기') |
| `market.mode: results` | 지난 결과 네 구역: 그림, 이름 전체, 낙찰자, 낙찰가. 넘치면 `resultPage`로 넘기고 페인터가 `resultPages`를 쓴다 | `market-back` |
| `market.mode: rules` | 거래 규칙 여덟 줄 | `market-back` |

우선순위: 상점 알림, 분류 겹창, 암시장 알림, 확인 창, 결과, 규칙. 겹창이 있으면 아래 버튼은 등록하지 않는다.

## 페인터 계약

`window.ShopPainter.draw(A)`. 매 프레임 캔버스를 지우고 다시 그린다.

- 읽는 것: `A.ctx, w, h, background, time, reduced, s, items, item, max, balance, limits, art, currency, hit`.
- 쓰는 것: `s.perPage`, `s.page`(범위 보정), `s.detailPages`, `s.detailPage`(범위 보정), `s.market.resultPages`, `s.market.resultPage`(범위 보정). `s.qty`는 쓰지 않고 표시만 1..최대로 맞춘다.
- 암시장 동작: `market-select, market-amount, market-bid, market-cancel, market-confirm, market-back, market-results, market-result-previous, market-result-next, market-rules, market-refresh, market-mail`.
  금액 칸 포커스 표시 키는 `market-amount:구역`.
- 재료 목록: `A.materials`(문자열 배열)가 있으면 그것을 쓰고, 없으면 `s.data.shop`과 `A.items`의 `materialTab`에서 모은다.
- 탭은 문자열 또는 `{ id, name }`, 재화는 `{ gold: n }` 객체 또는 `[{ goods, amount }]` 배열을 받는다.

일반 상점은 선택과 구매 완료 때 짧게 효과음을 재생한다. 암시장은 기존 파일과 음량(클릭 0.16, 나머지 0.28)을 유지하고, 입찰 때 봉인음 또는 취소음 후 180ms 뒤 동전 소리를 재생한다. 별도 효과음 버튼은 표시하지 않는다. 화면을 떠나면 예약된 소리와 재생 중인 소리를 정리한다. 출처는 public/assets/shop/CREDITS.md에 기록한다.
