# 낙원 · 천상의 회랑과 지옥

콘텐츠 → 사냥 → 낙원(`/paradise`)에서 천상 또는 지옥을 선택한다. 천상은 입장권 1장으로 1층부터 시작한다. 천상·지옥은 캐릭터의 바깥 HP·MP를 변경하지 않고 `paradise.resources`에 별도 HP·MP를 최대치로 생성한다. 전투·스킬·장비·물약·증강·거울 전투는 이 수치를 사용하며, 이후 전투와 재접속에도 이어진다. 귀환·패배·완주 시 바깥 수치를 복원하거나 덮어쓰지 않는다. 이전 형식의 진행 중 탐험에는 입장 전 수치가 없으므로 현재 저장된 HP·MP부터 분리한다. 지옥은 아래 별도 규칙을 사용한다. 새로고침·재접속으로 사건이나 선택지가 다시 추첨되지 않는다. 탐험 중 장비 변경과 다른 필드 입장은 기존 전투 제한을 따른다.

## 운영 설정

운영 DB `rpgenius_data`의 `Paradise`를 관리자 **원본 데이터**에서 설정한다. 서버 시작이나 import에서는 아이템·상점·보상 데이터를 생성하거나 수정하지 않는다.

```json
{ "enabled": true, "baseRewards": [] }
```

`enabled`는 천상 신규 입장을 제어하며 지옥은 `hell.enabled`를 사용한다. 진행 중인 탐험과 종료 보상 수령은 입장을 닫아도 가능하다. `baseRewards: []`는 기본 보상을 지급하지 않는 명시적 설정이다. 카드 확정 계약은 기본 보상과 별도로 지급한다. 입장권 획득처는 운영자가 기존 상점/보상 설정으로 결정한다. 자동 판매나 무료 지급은 없다.

기본 보상 항목은 `type`(골드/경험치/아이템), `count`(양의 정수 지급량), `perFloors`(지급 기준 층 간격)를 가진다. 아이템은 운영 아이템 이름 `name`도 필요하다. 예시이며 자동 적용하지 않는다.

```json
{
  "enabled": true,
  "baseRewards": [
    { "type": "골드", "count": 1000, "perFloors": 10 },
    { "type": "아이템", "name": "강화석", "count": 5, "perFloors": 20 }
  ]
}
```

정산량은 `floor(최고 클리어 층 / perFloors) × count × 종료 보상 배율 × 전투 보상 배율 평균`을 내림한다. 붕괴 수락 전투와 저주받은 목걸이의 엘리트 보상 배수를 전투 보상 배율에 반영한다. 사건 전투의 강화·계약·유물 보상에도 배수를 적용하며, 특별 보스의 유물은 특별 유물 1개와 추가 일반 유물로 지급한다. 승리하지 않고 이동한 층은 클리어 기록에 포함하지 않는다. 기본 보상은 입장 시 운영 설정을 탐험에 저장한다. 이후 운영 변경은 다음 탐험부터 적용한다. 탐욕의 인장은 3승 완료 후에만 계약이 확정된다.

**천상은 증강 선택 단계에서 직접 귀환해야 정산할 수 있다.** 전투·사건·퍼즐 중 귀환은 화면과 서버에서 차단하며 기존 필드 퇴장 명령에도 적용한다. 전투 패배 시 기본·달성·계약 보상은 지급하지 않는다. 단, 천상 특수능력 마지막 은총이 있으면 정산될 천상의 증표의 50%만 지급하며 이를 수령한 뒤 재입장한다. 주간 최고 기록은 유지한다. 999층 수문장 격파 후에도 증강 단계에서 귀환을 선택하며 추가 탐험은 불가능하다. 이전 버전의 미수령 완주 기록은 귀환 동작을 거친 뒤 수령한다. 이미 지급된 보상은 변경하지 않는다. 지옥의 마지막 클리어 층 보상 규칙은 그대로 유지한다.

획득 목록은 유물·증강·계약 탭으로 구분한다. 유물에는 개별 이미지를 표시하고, 계약 탭에는 확정 보상과 도전의 남은 전투·달성 여부를 표시한다. 각 탭은 내용 길이에 맞춰 페이지를 나눈다. 유물 14종은 built-in imagegen으로 개별 제작했으며 기존 아이템과 같은 투명 여백을 맞췄다. S3의 `tcgenius/assets/ui/낙원/relic-*.webp`를 기존 `/rpg-ui` 경로로 제공한다. 생성 프롬프트와 파일 목록은 [유물 에셋 기록](paradise-relic-assets.json)에 있다.

보상 수령은 탐험당 한 번이다. 카드 공간이 부족하거나 운영 보상 아이템이 사라진 경우, 보상을 소비하지 않고 정리/설정 수정 후 재시도할 수 있다. 전직 카드의 화면 등급과 내부 인덱스(5성→4, 9성→8)를 기존 카드 규칙에 맞춘다.

신규 누락 항목을 명시 등록할 때만 실행한다. 기존 아이템 ID·설명·운영자가 비워 둔 설정·상점 구성을 보존한다.

```powershell
node scripts/register_paradise_content.js
node scripts/register_paradise_content.js --apply
```

## 진행 규칙

- 첫 조우는 일반 몬스터다. 이후 증강을 선택하면 일반 전투, 엘리트 전투, 무작위 사건 중 두 갈림길을 독립 추첨한다. 일반/일반처럼 같은 종류도 나온다. 기본 비중은 사건 15%, 엘리트 15%, 일반 70%이며 뒤틀림 25 이상에서는 사건 15%, 엘리트 30%, 일반 55%다. 각 길에는 독립적으로 20% 확률로 특수 기믹이 붙는다. 길과 후보 ID를 저장하므로 재접속해도 유지되며, 길 선택 시 층을 다시 올리지 않는다. 강제 엘리트, 지정 사건, 붕괴, 999층 수문장은 갈림길을 생략한다. 첫 전투 전 시작 증강도 기존처럼 첫 일반 전투로 이어진다.
- 증강 세 후보는 하나의 등급으로 통일하며 개별 새로고침도 같은 등급을 유지한다. 일반 승리의 실버/골드/프리즘/저주 비중은 40/35/20/5%, 엘리트 승리는 25/30/40/5%다. 뒤틀림 50 이상에서는 각각 35/30/15/20%, 20/25/35/20%다. 자격을 충족하는 미획득 후보가 남은 등급에서 추첨하며, 가능한 경우 후보 세 개가 남은 등급을 우선한다. 기존 혼합 등급 선택지는 최초 조회 때 한 번만 새 규칙으로 저장한다.
- 모든 층에서 엘리트 한 마리를 처치할 때마다 60% 확률로 유물 선택을 제공한다. 세 후보 중 하나를 고른 뒤 증강으로 진행하며 이미 보유한 유물과 특수 유물은 후보에서 제외한다. 연속 전투에서 여러 번 획득하거나 갈림길 보상이 겹치면 전투를 마친 뒤 차례로 선택한다. 20분 제한은 증강 선택, 갈림길 선택, 이벤트 선택지에서 멈추며 재접속해도 유지된다. 전투와 퍼즐 풀이, 유물 선택 중에는 시간이 흐른다. 시간을 바치는 기믹의 명시적인 비용은 정지 여부와 관계없이 차감한다.
- 사건·전투를 마치면 아직 얻지 않은 강화 중 최대 3개를 제시한다. 장비 강화는 실제 장착한 지원 장비만 제시한다. 공통 증강 204개, 장비 전용 증강 72개, 캐릭터 전용 증강 34개로 총 310개다. 월야섬은 신규 추첨과 도감에서 제거했다. 이미 진행 중인 해당 전투의 계약은 보존한다. 일시 효과가 끝나거나 거울과 거래해 버린 증강도 같은 탐험에서 다시 나오지 않는다. 남은 선택지가 없으면 5층을 이동해 계속 진행한다. 도감의 ‘천상’에서 증강과 유물을 나누어 검색할 수 있다. 증강은 효과와 층수 변화를, 유물은 개별 이미지와 일반/고급/특수 등급을 표시한다. 설명은 모두 합니다체로 제공하며 등장 조건 안내 문구는 표시하지 않는다. 실제 장착·유물·계약 조건 검사는 서버에서 유지한다.
- 천상 최고 기록과 주간 순위는 통과한 층을 집계한다. 전투 조우와 단순 이동만으로 도착층을 기록하지 않으며 승리 후 확정한다. 연속 전투는 마지막 적까지 모두 이겨야 기록한다. 비전투 사건을 마친 방은 통과로 인정하고, 패배하면 직전까지 확정한 최고 기록을 유지한다. 첫 전투 패배는 0층이며 순위에 등록하지 않는다. 타임아웃 자동 귀환의 도달층 정산은 기존 규칙을 유지한다. 배포 전에 이미 저장된 과거 주간 기록을 소급 삭제하거나 초기화하지 않는다.
- 이동은 1~999층으로 제한한다. 999층에 도착하면 마지막 수문장 전투로 진행하고, 승리해야 완주한다.
- 천상 권장 전투력은 몬스터 스탯을 캐릭터와 동일한 `computeCombatPowerFromStats`로 환산한 값이다. 플레이어가 몬스터를 상대하는 데 필요한 전투력을 역산하는 필드용 `getDungeonRecommendedCP`와 구분한다. 기준층은 1층 1만, 10층 10만, 100층 100만, 200층 500만, 300층 1000만, 400층 3000만, 500층 6000만, 600층 1억, 700층 3억, 800층 4억, 900층 5억, 999층 10억이며 사이 층은 선형 보간한다.
- 몬스터 HP는 목표 전투력의 약 50%로 선형 증가하고, 방어력은 목표 전투력 제곱근의 50%로 증가한다. 나머지 전투력을 공격력으로 맞추며 정수화 오차만 HP로 보정한다. HP의 제곱근을 사용하는 전투력식에 방어 비중 75%를 강제해 HP가 과도하게 커지던 배분은 폐기했다. 13층 도박사는 자체 전투력 15.6만, HP 약 7.8만이다. 엘리트는 1.2배, 심판자는 3.5배, 균열 보스는 4배이며 최종 수문장의 목표 전투력은 10억이다. 특성, 저주, 붕괴 등 추가 강화까지 모두 적용한 뒤 최종 방어력을 10,000으로 제한한다. 줄어든 방어력을 다른 스탯에 재분배하지 않으므로 상한이 적용된 몬스터의 실제 전투력은 목표보다 낮다. 진행 중인 구형 천상 전투는 낙원 API 접근 시 남은 HP 비율과 진행 상태를 보존하여 한 번 보정하며 지옥과 거울은 이 스탯 재계산에서 제외한다. 방어력 상한은 거울을 포함한 천상 적에게 적용하고, 현재 버전의 진행 중 전투는 방어력만 제한하여 남은 HP, 공격력, 쿨타임을 그대로 둔다.
- 심판자 사건은 150층 이상에서만 등장한다. 심판자는 최종 피해 35% 증가, 종료 보상 50% 증가 효과의 심판자의 성흔과 7성 전직 카드 계약을 준다. 선택지 메시지와 정산 미리보기에도 같은 효과를 반영한다. 균열 보스는 공격력 +70%, 받는 피해 -20%, 종료 보상 +100% 유물과 8성 전직 카드 계약을 준다.
- 퍼즐은 기존 일일 지혜 퍼즐의 암호/순서 추론 두 유형을 재사용한다. 서버 기준 120초, 단 한 번 제출하며 실패는 현재 HP -15%. 건너뛰기는 +5층, 무페널티. 해답은 클라이언트에 보내지 않는다.
- 대장장이는 지원 장비 72개 중 유효 장착 장비가 있을 때만 출현한다. 수치형 패시브를 회랑 안에서 증폭하고 장비 원본은 변경하지 않는다. 전용 증강도 같은 장착 조건을 사용한다. 장착 요구 캐릭터/등급이 맞지 않아 비활성인 장비는 제외한다.
- 거울은 천상 증강·유물을 제외한 동일 카드·장비·각성 패시브·스킬·전직 궁극기, HP·MP 100%로 등장한다. 기존 PVP의 스킬/패시브 AI가 플레이어의 공격 없이도 시간에 따라 행동한다. PVP의 HP 5배 보정·랭킹·일일 보상은 적용하지 않는다. 생존 패시브는 복제본마다 독립적으로 저장하며 WebGL에서 좌우 반전과 실제 적 스킬 타격을 재생한다.
- 확률 이벤트 성공률에 주사위 +18%p. 회랑 열쇠는 상자 좋은 결과 확률 +22%p, 황금 상자의 희귀 계약 확률 0.5%→1.05%. 희귀 결과에는 8성 각성 카드, 8성 전직 카드, 종료 보상 +100% 계약이 있다. 열기 전에는 구체적인 희귀 보상을 노출하지 않으며 실제 결과만 즉시 표시한다. 확률형 증강도 결정된 결과를 표시하고 재요청으로 재추첨되지 않는다.

뒤틀림 이동 구간은 +5층 이하 0, +6~15층 +5, +16층 이상 +15, 층 감소 -5. 퍼즐 성공 -10, 위험 계약 +10, 엘리트 처치 -5. 50 이상은 저주 선택지/특수 사건과 특성 몬스터가 늘고, 75 이상은 몬스터 특성 확률이 20%→65%가 된다. 100이면 붕괴 선택을 먼저 처리한다. 붕괴 수락/균열 선택 후 뒤틀림은 50으로 안정화한다.

임시 효과는 **승리한 전투 수**로 차감한다. 연속 전투는 개별 몬스터마다 1회 차감한다. 악마의 거래는 HP·MP 회복을 모두 막으며, 치명타 방지/보험/깃털은 HP 1의 생존만 남는다. 동일 유물 중복 획득은 없고 일반 유물을 모두 보유하면 공격력 +5%로 대체한다.

## 탐험·계약·전투 메커니즘 증강

`paradise_augments_adventure.js`의 30개는 공격 순서, 쿨타임, 보호막, 유물 거래, 조건부 보상 계약과 잭팟을 다룬다. 불꽃 저금통은 비치명타 세 번을 확정 치명타로 전환하고, 메아리 저장고는 이전 타격을 두 번째 타격에 더한다. 복수의 금고는 잃은 HP를 다음 스킬에 담고, 남은 일격의 행선지는 초과 피해를 다음 적에게 전달한다. 자동 공격은 이 효과들을 충전·소모하지 않는다. 추가 피해도 거울의 방어·회피·보호막 판정을 거친다.

계약은 `run.quests`에 남은 전투·달성 수·성공/실패를 저장한다. 일반 공격만 사용, 서로 다른 스킬 사용, 치명타 누적, 무피격 승리 등을 판정하며, 성공 시 카드 계약이나 유물을 한 번 지급하고 결과 연출을 표시한다. 탐험을 중단하면 미완료 계약은 실패한다. 회복 계약은 회복 봉쇄를 따른다. 유물 반납·소각은 특별 보스 유물과 소모한 깃털을 제외한다. 도박 결과는 선택 즉시 공개하고 기존 요청 영수증으로 재추첨·중복 지급을 막는다.

카드 계약을 주는 증강, 유물, 갈림길 기믹은 같은 후보군의 다른 후보 대비 35% 가중치로 추첨한다. 등급 비중, 이벤트 15%, 기믹 20%, 엘리트 유물 60%는 유지한다. 전투로 카드 계약을 얻는 증강은 선택 후 이동한 층의 권장 전투력이 현재 플레이어 전투력의 80~130%일 때만 제시하고 선택 시에도 다시 검사한다. 강제 엘리트는 1.2배를 반영하며, HP 1로 만드는 정예 사냥의 잔여 횟수가 있으면 사신 계약을 제외한다. 시작 증강에는 전투 카드 계약을 제시하지 않는다. 저장된 부적합 선택지는 같은 등급으로 교체하며 다른 선택지와 사용한 새로고침 횟수는 보존한다. 이미 획득한 카드 계약과 수락한 사신 계약의 저장 보상은 소급 하향하지 않는다.

반복 카드 계약은 탐험 전체에서 횟수를 제한한다. 한탕 적금과 장례 보험금은 각각 해당 방식의 처치 5회마다 5성 일반 카드 1장, 최대 2장이다. 대단원의 배당은 궁극기 5회마다 6성 일반 카드 1장, 최대 3장이며 이후에도 HP와 MP 20% 회복은 유지한다. 패치 전 대단원의 배당으로 획득한 카드도 한도에 포함한다. 두 번째 영수증은 조건부 5승에 7성 각성 카드 1장, 마지막 티켓은 저체력 3승에 6성 일반 카드 1장으로 탐험당 한 번만 준다. 룬 깃펜은 일반 스킬 두 종류 이상 사용 후 3승마다 6성 일반 카드 1장, 최대 2장이다. 검 한 자루의 약속은 일반 공격만 사용하는 3승으로 늘리고, 마법사의 증명은 6성 전직으로 낮춘다. 신비한 계약과 헌 유물 보상은 5성 일반, 빈손으로 왕좌까지는 8성 전직을 지급한다. 일곱 번째 종소리는 777에 8성 각성, 다른 세 숫자 일치에 7성 전직, 두 숫자 일치에 6성 일반을 지급한다. 계약 복제는 35%, 장난신의 선물은 25% 확률로 6성 각성을 지급한다.

등급은 실버 74개, 골드 147개, 프리즘 53개, 저주 14개다. 추첨은 개수와 무관하게 등급을 먼저 고른다. 기본 가중치는 실버/골드/프리즘/저주 40/35/20/5, 뒤틀림 50 이상에서는 35/30/15/20이다. 해당 등급에 선택 가능한 증강이 없으면 나머지 등급에서 추첨하며, 가능하면 세 장이 모두 같은 등급으로 나오지 않도록 세 번째 장을 다른 등급에서 고른다.

## 천상 증강 밸런스와 캐릭터 전용 증강

악마의 거래는 공격력 증가를 제거하고 기존 추가 피해 계산에 66.6%를 더한다. 모든 회복 무효는 유지하며, 이미 획득한 구형 탐험에도 계산 시 같은 효과를 적용한다. 복제된 축복은 추첨·선택·도감에서 제거한다. 저장된 선택지에 제거된 증강만 남았다면 계속 진행할 수 있다. 상처 없는 결투의 달성 보상은 탐험 중 공격력 +25%이며 진행 중인 구형 계약에도 적용한다. 새 사신과의 계약은 8성 각성 카드 계약과 HP, MP 완전 회복을 지급한다. 이미 수락한 사신 계약은 저장된 보상을 유지하고 이미 정산한 계약은 다시 지급하지 않는다. 회복은 악마의 거래의 봉쇄를 따른다.

`paradise_augments_characters.js`는 플레이 가능한 17개 캐릭터 계열마다 2개씩 총 34개를 정의한다. 현재 메인 카드 계열이 맞고 필요한 기술을 실제로 보유한 경우에만 제시·적용하며, 일반·전직·각성 카드에 동일한 계열 판정을 사용한다. 모든 효과는 천상 탐험 안에서만 작동한다. 일반 필드·지옥·거울 복제본에는 적용하지 않는다. 도감에서 카드 전용 필터와 캐릭터 이름 검색을 지원한다.

광란의 익테봇은 소환수 공격 주기를 4초에서 2초로 줄인다. 고독한 이익태는 자폭을 포함한 스킬을 봉인하고 직접 일반 공격 피해를 2배로 만든다. 그 외 자인 재시전, 시벌론 연장, 보호막 반격, 생존 후 스킬 초기화, 치명타 연계, 한탕 카드 계약, 확정 잭팟, 건력 유지, 중첩 유지, 유서 피해 저장, 헤즈업 이중 추첨, 모드 순환, 정신력 회복 등을 지원한다. 추가 피해는 거울 방어 판정을 거치며 자동·소환·지속 공격으로 직접 공격 조건을 충전하지 않는다. 계약과 탐험 한정 효과는 탐험에, 전투별 효과는 전투 기록에 저장한다.

모바일 낙원 적의 최대 폭을 화면의 46%에서 66%로 키우고 중심 위치·발 위치·타격 지점을 함께 조정한다. 모바일 일반 알림은 최대 2줄·2.8초, 확률/계약 결과는 최대 3줄·4.2초로 표시한다. 긴 알림은 자세히 보기를 눌러 전체를 확인하고 즉시 닫을 수 있다. 천상 입장 저장이 성공한 뒤 입장권·문 열림·빛 입자 연출을 1.85초 재생하고 첫 전투로 이어진다. 동작 줄이기 설정에서는 0.18초 전환만 사용하며 재접속에는 입장 연출을 반복하지 않는다.

## 주간 개인 기록과 랭킹

`user.paradiseWeekly`에 `week`, `bestFloor`, `reachedAt`을 저장한다. 순위는 최고 도달층 내림차순, 동층은 먼저 도달한 순이다. 도달 기록은 이동/전투 시작/승리 시 저장하고 하락·패배·귀환·재입장으로 줄어들지 않는다. 보상용 최고 클리어 층과 별개다.

기존 `getKoreanWeekKey`를 그대로 사용해 **월요일 00:00 KST**에 개인 기록과 랭킹을 함께 초기화한다. 지난 주 기록은 `paradiseWeeklyHistory`에 보존한다. 주를 넘겨 진행 중인 탐험은 새 주에 도달/승리한 층부터 기록한다. 랭킹 API `/api/paradise/ranking`은 인증된 사용자에게 상위 100명과 본인 순위를 제공한다.

`paradise_rewards.js`가 주차 변경을 1분 간격으로 확인하고, 서버 재시작 시에도 미지급 주차를 확인한다. 일관된 읽기로 지난 주 기록을 조회한 뒤 `ParadiseSettlement:주차`에 순위와 보상 설정을 확정한다. 새 주 탐험 요청도 정산 확인을 거친다. 우편 본문은 기존 `rpgenius_mail`, 수신함은 기존 `user.mail`을 사용한다. 계정·주차별 고정 우편 ID와 `systemMailDeliveries` 지급 표식을 조건부 저장해 부분 실패·동시 실행·재시작·우편 삭제 후에도 중복 발송하지 않는다. 우편 지급 완료 후 주차 완료를 기록한다. 접속하지 않은 참가자도 지급 대상이다.

## 2026-10-20 보상 설정

사용자 결정에 따라 **매 탐험 최고 도달층에 해당하는 구간 하나**를 귀환 보상으로 지급한다. 증표 수량을 기존의 100배로 늘려, 100층에서 내려와 귀환해도 기본 증표 300개다. 1/10/100/200/300/400/500/600/700/800/900/999층의 기본 수량은 각각 **100/200/300/400/500/600/700/800/1000/1500/2000/3000개**다. 누적 구간 합산이나 주간 1회 보상이 아니다. 기존 종료 보상 증가 계약과 유물은 이 기본 수량에 적용하고 소수점은 내린다. 입장 시 `milestoneRewards`를 저장하므로 운영 설정 변경은 다음 탐험부터 적용한다. 전투에서 패배하면 증표와 계약 보상을 모두 지급하지 않는다.

주간 1위는 찬란한 지옥 열쇠 3개·2000가넷, 2위는 화려한 지옥 열쇠 3개·1000가넷, 3~5위는 지옥 열쇠 3개·500가넷이다. **상위 5명을 포함한 모든 참가자에게 지옥 열쇠 3개를 추가**한다. 따라서 3~5위의 합계는 지옥 열쇠 6개·500가넷이다. 참가 기준은 해당 주에 1층 이상 기록을 남긴 계정이다. 주간 우편에는 탐험 중 보상 배율을 적용하지 않는다.

`node scripts/register_paradise_content.js --configure-rewards --apply`로 요청한 보상 아이템 4종과 `milestoneRewards`, `weeklyRewards` 설정을 명시 등록했다. 기존 아이템과 상점·입장권 획득처·기타 운영 설정은 보존한다. 일반 서버 시작은 이 등록 작업을 실행하지 않는다.

증강과 이동 사건에 서버 계산 `powerWarning`을 제공한다. 도착층(최대 999층)의 권장 전투력이 현재 회랑 전투력의 1.1배 이상일 때 표시하며, 확정 엘리트/균열 보스/999층 수문장의 배율도 반영한다. 확률 이동은 성공한 경우를 표시한다. 선택 후 얻을 능력치와 다음 무작위 조우까지 예측하는 수치가 아니라 현재 전투력 기준의 사전 안내이며 선택을 막지 않는다.

## 지옥

지옥은 지하 1층에서 시작해 지하 100층까지 내려간다. 입장 전 HP·MP와 관계없이 입장 시 모두 100%로 시작하며, 탐험 중에는 남은 HP·MP가 다음 전투로 이어진다. 지옥 열쇠·화려한 지옥 열쇠·찬란한 지옥 열쇠 중 선택한 열쇠 1개를 소비하며 낙하 횟수는 각각 5·6·7회다. 전투 승리 후 좌우 중 한쪽으로 낙하하면 서버가 **1~10층 65% / 11~15층 25% / 16~20층 10%**로 구간을 추첨하고, 구간 안에서는 층별 균등 확률을 적용한다. 로켓 점프를 얻으면 다음 낙하는 16~20층에서 균등 추첨한다. 100층을 넘어가는 이동은 100층에 도착한다.

기존 난이도 보정 기준은 `30000 * (1 + floor(현재층 / 10))`이다. 1~9층 3만, 10~19층 6만, 100층 33만이며 UI에서 수치를 나열하지 않는다. 이번 밸런스 변경부터는 이 보정으로 생성한 몬스터의 **현재·최대 HP만 10배**로 올리며 공격력·방어력은 그대로다. 이미 조우한 적은 보존하고 새 조우부터 적용한다. 첫 방은 일반 몬스터이고 이후 일반·엘리트·보스의 확률은 60%·30%·10%로 두었다. 100층은 보스다. 기존 필드 몬스터와 전투 엔진을 재사용한다. 천상의 증강·사건·뒤틀림·주간 기록은 지옥에 적용하지 않는다.

11·22·33·44·55·66·77·88·99층에 **도착하면** 전투 대신 제단이 나타난다. 지나친 층의 제단을 소급해서 사용하지 않는다. 제단은 한 번만 사용하며 일반 상자 추가 40%, 낙하 1회 추가 20%, 로켓 점프 20%, 풍요로운 상자 추가 20%다. 제단 사용을 해당 층 클리어로 기록한다. 마지막 낙하로 도착한 제단에서도 낙하 횟수를 얻으면 탐험을 계속한다.

낙하 횟수를 모두 사용한 뒤 도착층을 클리어하거나, 100층을 클리어하면 상자를 선택한다. 사망·포기도 **마지막 클리어 층**으로 상자를 지급한다. 클리어한 층이 없으면 보상 없이 종료한다. 사용한 열쇠는 돌려주지 않는다.

기본 후보는 3개이며, **개봉은 항상 1회**다. 제단의 상자 추가와 풍요로운 상자 추가는 **선택 후보만 1개씩** 늘린다. 풍요로운 상자 추가로 생긴 후보는 풍요로움이 확정이며 다른 후보는 각각 10% 확률이다. 후보 종류는 입장 시 저장한 운영 보상표의 weight 비중으로 중복 없이 추첨한다. 이미 뽑힌 종류를 제외하고 남은 가중치를 다시 합산하며, 가중치가 0인 종류는 나오지 않는다. 추가 후보에도 같은 규칙을 적용한다. 보상 종류가 부족하면 가능한 종류까지만 제시하며 풍요로운 후보 보장은 유지한다. weight가 없는 구형 보상표는 항목마다 동일한 가중치를 사용한다. 종류 및 실제 내용물은 종료 시 한 번 확정해서 저장한다. 재접속이나 중복 요청으로 재추첨되지 않는다. 이전 규칙으로 저장된 탐험도 화면을 다시 불러오거나 동작을 요청할 때 개봉을 1회로 제한한다. 이미 상자를 개봉했다면 지급한 보상은 보존하고 추가 개봉 없이 종료한다.

### 장비 수치 상향 근거

공격 전투력은 공격력 비율로, 방어 전투력은 `sqrt(HP × (1 + 방어력 / 100))` 비율로 비교하고 기타 전투력은 유지했다. 공격력에 비례하지 않는 고정 피해나 HP 증가에 따른 회복 계수 감소까지 비례 성장으로 간주하므로 전투력 상승을 보수적으로 크게 잡는 근사다. 생존력 비교는 관통·회피·회복을 제외한 `HP × (1 + 방어력 / 100)` 기준이다.

7개 샘플의 환산 차이는 약 1.5~7.5층이다. 위 3개 주요 샘플의 공격·방어 전투력 중 더 큰 상승 비율을 1~999층 전체 곡선에 대입해도 환산 차이는 최대 약 44~85층으로 100층 미만이다. 장비가 전혀 없는 상태와 변경 +25를 비교하는 더 큰 증가 비율도 같은 3개 샘플의 전체 층 곡선에서 100층 미만임을 테스트로 확인했다. 이 고층 검토는 같은 능력치 증가 비율이 유지된다고 가정한 계산이다. 이는 장비의 순수 능력치 영향 비교이며 실제 도달 층 예측이나 상한 보장은 아니다. 증강·유물·스킬 조합, 회복과 시간 제한은 별도로 영향을 준다. 공격력과 방어구를 같은 10배로 올리면 HP와 방어력의 곱 때문에 생존력 증가가 지나쳐, 방어구는 3배로 제한했다.

로비는 Claude CLI의 claude-opus-5-5에 시각 구현을 위임하고 기존 WebGL 장면에 결합했다. 장비 해금·강화 성공/실패·줄별 재설정 연출, 모바일 스크롤, 랭킹 구간별 이미지 보상을 제공한다. ImageGen으로 만든 공통 아이콘 3개는 기존 S3 ui/낙원 경로로 등록했으며 [제작 기록](paradise-progression-assets.json)에 정리했다.

## 지옥 상자 확률과 보상 화면

첫 상자는 각성 카드 2.5%, 전직 카드 2.5%, 보주 6%, 일반 카드 6%, 천상 입장권 6%, 보호권 10%, 초월 조각 10%, 초대장 12%, 열쇠 12%, 황금 주머니 12%, 미끼 12%, 검은 불 9%로 추첨한다. 이후 후보는 이미 뽑은 종류를 제외한 상대 가중치로 추첨한다. 보상 수량과 아이템 연결은 변경하지 않는다. 운영 변경은 scripts/update_paradise_hell_weights.js --apply를 명시 실행하여 백업, 이전 값 조건부 저장, 읽기 검증을 거친다. 실행 중인 탐험의 저장된 보상표와 이미 생성된 상자는 보존한다.

Claude CLI claude-opus-5-5에 갈림길 봉인과 지옥 보상 화면의 시각 구현을 위임했다. 기존 WebGL 배경과 상자 이미지에 보상 종류, 단계, 수량을 분리해 표시한다. 풍요로운 상자는 금빛 프레임과 이미 3배로 계산된 강화석 수량을 표시하며, 획득 화면은 아이콘 중심으로 구성한다. 모바일은 좌우 탐색, PC는 세 상자 비교를 제공한다.

관련 기존 테스트 212개를 확인했으며 마지막 수정 뒤 천상/지옥 API와 기믹 전투 테스트 152개를 다시 통과했다. Chrome 1440×900, 390×844, 320×640에서 상자 후보, 실제 개봉과 수량, 종료 화면, 갈림길 안내와 일시정지 표시를 확인했다. 테스트는 격리된 기존 Express 테스트 데이터를 사용했으며 운영 유저 데이터에 쓰지 않았다. 요청한 운영 가중치만 백업 후 조건부 갱신하고 읽기 검증했다.


## 상태 조회 최적화

낙원 응답 한 개에서 능력치와 전투력을 재사용하고 다음 요청에서는 새로 계산한다. 전투 표시를 만들기 위해 별도 H필드 전체 상태를 만들던 호출을 없앴다. 주간 랭킹은 이름과 주간 기록만 읽으며 전체 가방과 장비를 복제하지 않는다. 클라이언트는 진행 중인 상태 조회와 랭킹 조회를 중첩하지 않고 행동 전송보다 오래된 조회 응답을 적용하지 않는다. 기존 계정별 실행 순서, 조건부 저장, 보상 재요청 검증은 유지한다.

기존 격리 API 테스트 환경에서 같은 1층 전투를 60회 조회한 결과 중앙 응답 시간은 33.21ms에서 10.30ms로 감소했다. 외부 호출 기준 능력치 계산은 요청당 10회에서 1회, 전투력 계산은 2회에서 1회로 감소했다. 이 수치는 로컬 처리 비용 비교이며 운영 DB/네트워크를 포함한 전체 지연 측정은 아니다.

천상 도감의 유물 목록은 Claude CLI claude-opus-5-5의 시각 제안을 반영했다. PC와 모바일 390px/320px에서 검색, 등급 필터, 유물 이미지와 설명을 확인했다. 작은 화면에서는 도감 종류를 가로로 배치해 목록을 가리지 않는다. 변경 관련 격리 검사 215개가 통과했다. 추가 실행한 기존 combat_power와 hfield_web 정적 검사는 각각 mental 능력치 분류와 캐릭터 표시 문자열에서 실패하며 변경 전 HEAD에서도 동일하게 재현했다.

### 낙원 상점과 보상 배율 정리

- 몬스터 처치 보상 배율은 제거했다. 이전 탐험의 `rewardUnits`도 정산에 사용하지 않으며 이벤트 능력치/카드/유물 보상은 복제하지 않는다. 저주받은 목걸이는 받는 피해 +10%, 종료 보상 +30%다. 붕괴 수락은 적 공격력 2배인 전투를 3회 모두 승리하면 종료 보상 +30%를 얻는다. 마력의 구슬은 전투 시작 시 MP 15%를 회복한다.
- 낙원 상점은 모든 로그인 사용자에게 공개한다. 상품과 가격은 운영 `Paradise.shop`을 읽는다. `scripts/register_paradise_shop.js --apply`를 명시 실행할 때만 신규 상점/누락 아이템을 등록하며 기존 운영 설정을 덮어쓰지 않는다.
- 천상과 지옥 입장은 141레벨부터 가능하다. 입장권/열쇠를 소비하기 전에 서버에서 레벨을 검사하고, 메뉴 표기는 `Lv.141 ~ Lv.300`으로 맞춘다.
- 루킴의 축복은 기존 1일 사용권으로 지급한다. 레전더리 장비 랜덤 상자는 기존 장비 상자 개봉 로직으로 레전더리 무기/방어구/장신구 중 하나를 지급한다. 상품은 자동 개봉하지 않는다.
- 거래권은 주간 10개, 100만 골드 입장권은 주간 1개, 1천만 골드 입장권은 별도로 주간 2개다. 1억 골드 입장권은 무제한이다. 주간 한도는 기존 한국 시간 월요일 00시에 초기화한다. 구매 한도와 재화 차감, 아이템 지급, 구매 영수증을 유저 문서에 함께 조건부 저장하고 동일 요청 재시도 시 재지급하지 않는다.

### 방어구 추가와 천공 장비 조정

`armor_expansion.js`는 일반/레어/유니크/레전더리 모자, 하의, 신발 12종을 정의한다. 요청 표의 0강/15강 방어력과 HP를 맞추고, 중간 강화는 기존 같은 등급 갑옷의 성장 비율을 따른다. 치명타 확률, 최대 HP 비율, 회피율, 쿨타임 감소 옵션은 강화로 증가하지 않는다. 동급 장비 상자에는 무기, 모자, 갑옷, 하의, 신발, 장신구가 포함되며 기존 유니크 레이드 장비 제외 규칙은 유지한다.

매의 눈 투구는 천리안의 왕관으로, 화룡의 비늘 하의는 불멸하는 업화의 하의로, 바람결의 장화는 폭풍을 걷는 발걸음으로 진화한다. 기존 동일 장비 10강 이상 3개 합성 규칙을 사용한다. `scripts/register_armor_expansion.js --apply`는 누락된 장비만 뒤에 추가하고 이 세 진화 대상은 운영 목록의 실제 인덱스로 연결한다.

천리안은 실제 치명타 확률 30% 이상에서 치명타 피해 +20%p, 업화는 화속성 저항 +200 및 현재 HP 20% 이하 피격 시 공격력 +20%(5초, 쿨타임 15초), 폭풍을 걷는 자는 쿨타임 감소가 20%를 초과하면 추가 +5%p를 적용한다. 필드, 천상/지옥, 거울/PvP, 레이드에서 같은 조건을 사용한다.

천공의 모자는 치명 명속성 추가 피해 10%(초월 단계당 +4%p), 천공의 갑옷은 명속성 공격 최종 피해 10%(+5%p), 천공의 하의는 비치명 명속성 추가 피해 8%(+3%p)로 변경한다. `scripts/update_sky_equipment_balance.js --apply`는 해당 수치와 설명만 갱신한다. 두 등록 스크립트 모두 운영 원본을 백업하고 이전 값이 같을 때만 저장하며, 서버 시작 시 자동 실행하지 않는다.

운영 장비 12종과 진화 대상, 천공 3종 변경을 명시 등록하고 읽기 검증했다. 백업은 운영 호스트 `/home/ubuntu/paradise-new-armor/`에 보관했다. 기존 격리 테스트 269개와 진화 경로 추가 검사가 통과했으며, 상점 일반 계정 구매와 140/141레벨 입장 경계를 실제 HTTP 경로로 확인했다.
