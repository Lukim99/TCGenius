# 낙원 · 천상의 회랑과 지옥

콘텐츠 → 사냥 → 낙원(`/paradise`)에서 천상 또는 지옥을 선택한다. 천상은 입장권 1장으로 1층부터 시작한다. 천상·지옥은 캐릭터의 바깥 HP·MP를 변경하지 않고 `paradise.resources`에 별도 HP·MP를 최대치로 생성한다. 전투·스킬·장비·물약·증강·거울 전투는 이 수치를 사용하며, 이후 전투와 재접속에도 이어진다. 귀환·패배·완주 시 바깥 수치를 복원하거나 덮어쓰지 않는다. 이전 형식의 진행 중 탐험에는 입장 전 수치가 없으므로 현재 저장된 HP·MP부터 분리한다. 지옥은 아래 별도 규칙을 사용한다. 새로고침·재접속으로 사건이나 선택지가 다시 추첨되지 않는다. 탐험 중 장비 변경과 다른 필드 입장은 기존 전투 제한을 따른다.

## 운영 설정

운영 DB `rpgenius_data`의 `Paradise`를 관리자 **원본 데이터**에서 설정한다. 서버 시작이나 import에서는 아이템·상점·보상 데이터를 생성하거나 수정하지 않는다.

```json
{ "enabled": true, "baseRewards": [] }
```

`enabled`는 천상 신규 입장을 제어하며 지옥은 `hell.enabled`를 사용한다. 진행 중인 탐험과 종료 보상 수령은 입장을 닫아도 가능하다. `baseRewards: []`는 기본 보상을 지급하지 않는 명시적 설정이다. 카드 확정 계약은 기본 보상과 별도로 지급한다. 입장권 획득처는 운영자가 기존 상점/보상 설정으로 결정한다. 자동 판매나 무료 지급은 없다.

기본 보상 항목은 `type`(골드/경험치/아이템), `count`(양의 정수 지급량), `perFloors`(지급 기준 층 간격)를 가진다. 아이템은 운영 아이템 이름 `name`도 필요하다. 예시이며 자동 적용하지 않는다.

```json
{
  "enabled": true,
  "baseRewards": [
    { "type": "골드", "count": 1000, "perFloors": 10 },
    { "type": "아이템", "name": "강화석", "count": 5, "perFloors": 20 }
  ]
}
```

정산량은 `floor(최고 클리어 층 / perFloors) × count × 종료 보상 배율 × 전투 보상 배율 평균`을 내림한다. 붕괴 수락 전투와 저주받은 목걸이의 엘리트 보상 배수를 전투 보상 배율에 반영한다. 사건 전투의 강화·계약·유물 보상에도 배수를 적용하며, 특별 보스의 유물은 특별 유물 1개와 추가 일반 유물로 지급한다. 승리하지 않고 이동한 층은 클리어 기록에 포함하지 않는다. 기본 보상은 입장 시 운영 설정을 탐험에 저장한다. 이후 운영 변경은 다음 탐험부터 적용한다. 사망·귀환·999층 완주 모두 획득한 계약을 보존한다. 탐욕의 인장은 3승 완료 후에만 계약이 확정된다.

보상 수령은 탐험당 한 번이다. 카드 공간이 부족하거나 운영 보상 아이템이 사라진 경우, 보상을 소비하지 않고 정리/설정 수정 후 재시도할 수 있다. 전직 카드의 화면 등급과 내부 인덱스(5성→4, 9성→8)를 기존 카드 규칙에 맞춘다.

신규 누락 항목을 명시 등록할 때만 실행한다. 기존 아이템 ID·설명·운영자가 비워 둔 설정·상점 구성을 보존한다.

```powershell
node scripts/register_paradise_content.js
node scripts/register_paradise_content.js --apply
```

## 진행 규칙

- 첫 조우는 일반 몬스터. 이후 기본 비중은 사건 35%, 엘리트 15%, 일반 50%. 뒤틀림 25 이상은 엘리트 30%.
- 사건·전투를 마치면 아직 얻지 않은 강화 중 최대 3개를 제시한다. 장비 강화는 실제 장착한 지원 장비만 제시한다. 일반 증강 121개와 장비 전용 증강 72개로 총 193개다. 일시 효과가 끝나거나 거울과 거래해 버린 증강도 같은 탐험에서 다시 나오지 않는다. 남은 선택지가 없으면 5층을 이동해 계속 진행한다. 도감의 ‘회랑 증강’에서 전체 효과와 층수 변화를 검색할 수 있다. 설명은 모두 합니다체로 제공하며 등장 조건 안내 문구는 표시하지 않는다. 실제 장착·유물·계약 조건 검사는 서버에서 유지한다.
- 이동은 1~999층으로 제한한다. 999층에 도착하면 마지막 수문장 전투로 진행하고, 승리해야 완주한다.
- 천상 권장 전투력은 몬스터 스탯을 캐릭터와 동일한 `computeCombatPowerFromStats`로 환산한 값이다. 플레이어가 몬스터를 상대하는 데 필요한 전투력을 역산하는 필드용 `getDungeonRecommendedCP`와 구분한다. 기준층은 1층 1만, 10층 10만, 100층 100만, 200층 1000만, 300층 3000만, 400층 6000만, 500층 1억, 600층 2억, 700층 3억, 800층 4억, 900층 5억, 999층 10억이며 사이 층은 선형 보간한다.
- 몬스터 HP는 목표 전투력의 약 50%로 선형 증가하고, 방어력은 목표 전투력 제곱근의 50%로 증가한다. 나머지 전투력을 공격력으로 맞추며 정수화 오차만 HP로 보정한다. HP의 제곱근을 사용하는 전투력식에 방어 비중 75%를 강제해 HP가 과도하게 커지던 배분은 폐기했다. 13층 도박사는 자체 전투력 15.6만, HP 약 7.8만이다. 엘리트는 1.2배, 심판자는 3.5배, 균열 보스는 4배이며 최종 수문장 자체 전투력은 10억이다. 특성·저주·붕괴 등 명시적인 추가 강화 후에는 실제 환산값도 함께 갱신한다. 진행 중인 구형 천상 전투는 낙원 API 접근 시 남은 HP 비율·특성·쿨타임·보상 상태를 보존하여 한 번 보정한다. 지옥과 거울 복제본은 제외한다.
- 심판자는 최종 피해 +35%·종료 보상 +50% 특별 유물과 8성 전직 카드 계약을 준다. 균열 보스는 공격력 +40%·받는 피해 -15%·종료 보상 +75% 유물과 9성 전직 카드 계약을 준다.
- 퍼즐은 기존 일일 지혜 퍼즐의 암호/순서 추론 두 유형을 재사용한다. 서버 기준 120초, 단 한 번 제출하며 실패는 현재 HP -15%. 건너뛰기는 +5층, 무페널티. 해답은 클라이언트에 보내지 않는다.
- 대장장이는 지원 장비 72개 중 유효 장착 장비가 있을 때만 출현한다. 수치형 패시브를 회랑 안에서 증폭하고 장비 원본은 변경하지 않는다. 전용 증강도 같은 장착 조건을 사용한다. 장착 요구 캐릭터/등급이 맞지 않아 비활성인 장비는 제외한다.
- 거울은 회랑 강화·유물을 제외한 동일 카드·장비·각성 패시브·스킬·전직 궁극기, HP·MP 100%로 등장한다. 기존 PVP의 스킬/패시브 AI가 플레이어의 공격 없이도 시간에 따라 행동한다. PVP의 HP 5배 보정·랭킹·일일 보상은 적용하지 않는다. 생존 패시브는 복제본마다 독립적으로 저장하며 WebGL에서 좌우 반전과 실제 적 스킬 타격을 재생한다.
- 확률 이벤트 성공률에 주사위 +10%p. 회랑 열쇠는 상자 좋은 결과 확률 +15%p, 황금 상자의 희귀 계약 확률 2%→3.5%. 희귀 결과에는 9성 각성 카드, 9성 전직 카드, 종료 보상 +100% 계약이 있다. 열기 전에는 구체적인 희귀 보상을 노출하지 않으며 실제 결과만 즉시 표시한다. 확률형 증강도 결정된 결과를 표시하고 재요청으로 재추첨되지 않는다.

뒤틀림 이동 구간은 +5층 이하 0, +6~15층 +5, +16층 이상 +15, 층 감소 -5. 퍼즐 성공 -10, 위험 계약 +10, 엘리트 처치 -5. 50 이상은 저주 선택지/특수 사건과 특성 몬스터가 늘고, 75 이상은 몬스터 특성 확률이 20%→65%가 된다. 100이면 붕괴 선택을 먼저 처리한다. 붕괴 수락/균열 선택 후 뒤틀림은 50으로 안정화한다.

임시 효과는 **승리한 전투 수**로 차감한다. 연속 전투는 개별 몬스터마다 1회 차감한다. 악마의 거래는 HP·MP 회복을 모두 막으며, 치명타 방지/보험/깃털은 HP 1의 생존만 남는다. 동일 유물 중복 획득은 없고 일반 유물을 모두 보유하면 공격력 +5%로 대체한다.

추가로 장비 전용 증강 50개를 지원한다. 마나번·최후통첩·잿불·천공·검은 잔향 계열, 궁택토·콰트로 1악장·감옥열쇠·범부의 대나무 등 전용 무기, 킹메이커 장신구·DMC 마이크·판테온 레거시, 현자의 마나번 로브·정복자의 최후통첩·심판의 주사위·해류를 거스르는 신발을 포함한다. 정확한 목록·배율은 `paradise_content.js`와 이를 그대로 제공하는 도감에서 확인한다.

장비 전용 증강 72종은 이번 탐험 내내 유지한다. 획득 기록을 기준으로 적용하므로 기존 탐험에서 이미 획득했거나 전투 횟수가 만료된 증강도 계속 적용하며, 남아 있는 구형 일시 강화와 중복 적용하지 않는다. 거울 거래로 포기하거나 탐험을 종료하면 해제한다. 대장장이 이벤트의 3회 전투 강화는 그대로 만료된다.

`staticPassive`가 있는 증강은 해당 장비의 상시·조건부 수치형 패시브까지 강화한다. 기본 장비 공격력·체력·방어력과 강화 단계는 바뀌지 않는다. 나머지는 설명에 명시한 발동형 효과만 강화한다. 발동 확률, 자원 소모량, 불이익은 기존 값을 유지하고 초월 단계에 따른 패시브 증가분도 같은 배율을 적용한다. 해류를 거스르는 신발은 쿨타임 감소 비율·감소 상한·MP 회복량을 함께 강화하며 회복 봉쇄를 따른다.

## 탐험·계약·전투 메커니즘 증강

`paradise_augments_adventure.js`의 30개는 공격 순서, 쿨타임, 보호막, 유물 거래, 조건부 보상 계약과 잭팟을 다룬다. 불꽃 저금통은 비치명타 세 번을 확정 치명타로 전환하고, 메아리 저장고는 이전 타격을 두 번째 타격에 더한다. 복수의 금고는 잃은 HP를 다음 스킬에 담고, 남은 일격의 행선지는 초과 피해를 다음 적에게 전달한다. 자동 공격은 이 효과들을 충전·소모하지 않는다. 추가 피해도 거울의 방어·회피·보호막 판정을 거친다.

계약은 `run.quests`에 남은 전투·달성 수·성공/실패를 저장한다. 일반 공격만 사용, 서로 다른 스킬 사용, 치명타 누적, 무피격 승리 등을 판정하며, 성공 시 카드 계약이나 유물을 한 번 지급하고 결과 연출을 표시한다. 탐험을 중단하면 미완료 계약은 실패한다. 회복 계약은 회복 봉쇄를 따른다. 유물 반납·소각은 특별 보스 유물과 소모한 깃털을 제외한다. 도박 결과는 선택 즉시 공개하고 기존 요청 영수증으로 재추첨·중복 지급을 막는다.

등급은 실버 48개, 골드 102개, 프리즘 29개, 저주 14개다. 추첨은 개수와 무관하게 등급을 먼저 고른다. 기본 가중치는 실버/골드/프리즘/저주 40/35/20/5, 뒤틀림 50 이상에서는 35/30/15/20이다. 해당 등급에 선택 가능한 증강이 없으면 나머지 등급에서 추첨하며, 가능하면 세 장이 모두 같은 등급으로 나오지 않도록 세 번째 장을 다른 등급에서 고른다.

## 주간 개인 기록과 랭킹

`user.paradiseWeekly`에 `week`, `bestFloor`, `reachedAt`을 저장한다. 순위는 최고 도달층 내림차순, 동층은 먼저 도달한 순이다. 도달 기록은 이동/전투 시작/승리 시 저장하고 하락·패배·귀환·재입장으로 줄어들지 않는다. 보상용 최고 클리어 층과 별개다.

기존 `getKoreanWeekKey`를 그대로 사용해 **월요일 00:00 KST**에 개인 기록과 랭킹을 함께 초기화한다. 지난 주 기록은 `paradiseWeeklyHistory`에 보존한다. 주를 넘겨 진행 중인 탐험은 새 주에 도달/승리한 층부터 기록한다. 랭킹 API `/api/paradise/ranking`은 인증된 사용자에게 상위 100명과 본인 순위를 제공한다.

`paradise_rewards.js`가 주차 변경을 1분 간격으로 확인하고, 서버 재시작 시에도 미지급 주차를 확인한다. 일관된 읽기로 지난 주 기록을 조회한 뒤 `ParadiseSettlement:주차`에 순위와 보상 설정을 확정한다. 새 주 탐험 요청도 정산 확인을 거친다. 우편 본문은 기존 `rpgenius_mail`, 수신함은 기존 `user.mail`을 사용한다. 계정·주차별 고정 우편 ID와 `systemMailDeliveries` 지급 표식을 조건부 저장해 부분 실패·동시 실행·재시작·우편 삭제 후에도 중복 발송하지 않는다. 우편 지급 완료 후 주차 완료를 기록한다. 접속하지 않은 참가자도 지급 대상이다.

## 2026-10-20 보상 설정

사용자 결정에 따라 **매 탐험 최고 도달층에 해당하는 구간 하나**를 종료 보상으로 지급한다. 100층에서 내려와 귀환해도 기본 증표 3개다. 1/10/100/200/300/400/500/600/700/800/900/999층의 기본 수량은 각각 **1/2/3/4/5/6/7/8/10/15/20/30개**다. 누적 구간 합산이나 주간 1회 보상이 아니다. 기존 종료 보상 증가 계약·유물·전투 보상 배율은 이 기본 수량에 적용하고 소수점은 내린다. 입장 시 `milestoneRewards`를 저장하므로 운영 설정 변경은 다음 탐험부터 적용한다.

주간 1위는 찬란한 지옥 열쇠 3개·2000가넷, 2위는 화려한 지옥 열쇠 3개·1000가넷, 3~5위는 지옥 열쇠 3개·500가넷이다. **상위 5명을 포함한 모든 참가자에게 지옥 열쇠 3개를 추가**한다. 따라서 3~5위의 합계는 지옥 열쇠 6개·500가넷이다. 참가 기준은 해당 주에 1층 이상 기록을 남긴 계정이다. 주간 우편에는 탐험 중 보상 배율을 적용하지 않는다.

`node scripts/register_paradise_content.js --configure-rewards --apply`로 요청한 보상 아이템 4종과 `milestoneRewards`, `weeklyRewards` 설정을 명시 등록했다. 기존 아이템과 상점·입장권 획득처·기타 운영 설정은 보존한다. 일반 서버 시작은 이 등록 작업을 실행하지 않는다.

증강과 이동 사건에 서버 계산 `powerWarning`을 제공한다. 도착층(최대 999층)의 권장 전투력이 현재 회랑 전투력보다 클 때 표시하며, 확정 엘리트/균열 보스/999층 수문장의 배율도 반영한다. 확률 이동은 성공한 경우를 표시한다. 선택 후 얻을 능력치와 다음 무작위 조우까지 예측하는 수치가 아니라 현재 전투력 기준의 사전 안내이며 선택을 막지 않는다.

선택지 경고는 붉은색 **위험! 권장 전투력 오버** 한 줄만 표시한다. 경고 영역과 접근성 설명에는 권장 전투력 수치·도착층·다음 조우 종류·성공 조건을 표시하지 않는다.

## 시각 자료와 확인

실제 화면은 `public/paradise.js`의 **WebGL 장면과 캔버스 HUD**다. CSS는 전체 화면 캔버스·접근성 버튼·퍼즐 입력 위치만 담당한다. 증강은 금속 문양 프레임과 고유 도안/실제 장비 이미지를 텍스처로 생성해 WebGL로 펼침·기울기·선택 섬광을 그린다. 모바일은 세 증강을 겹쳐 배치하고 좌우 탐색 후 선택한다. 사건은 전체 화면 일러스트 위에 게임 대사/선택 HUD를 그린다. 오류/재시도와 키보드·스크린리더 조작도 제공한다.

Claude CLI `claude-opus-5-5`에 최초 시각 설계 2회(합계 약 $0.26)를 맡긴 뒤, 2026-10-20에는 프런트엔드 직접 구현과 실제 스크린샷을 보고 수정하는 2단계 작업을 추가 위임했다. 추가 디자인 세션 누적 사용액은 약 $2.49이며 `output/paradise/redesign-opus.json`, `redesign-polish-opus.json`에 기록했다. 모서리를 깎은 금속 카드, 등급별 테두리, 확대 장비 메달리온, 간결한 하단 층수 표시와 전투력 경고를 구현했다. 모바일은 카드 전체를 축소하지 않고 실제 표시 크기로 텍스처를 그린다. 입장·귀환·수령 직후 중복 완료 문구가 버튼을 가리지 않도록 정리했다. 천상 종료 보상과 지옥 상자를 수령하면 서버 저장 성공 뒤에만 획득 연출을 재생한다. 광선·입자와 순차적인 카드 펼침, 금속 테두리의 빛, 기존 외부 효과음을 사용하고 실제 아이템 이미지·카드와 수량을 표시한다. 많은 보상은 페이지로 나누며 동작 줄이기 설정에서는 즉시 표시한다. 지급 실패 시 연출하지 않고, 동일 요청 재시도는 저장된 영수증의 동일 보상을 보여준다. 재접속 후 정산 화면에서도 실제 획득 목록을 확인할 수 있다.

## 지옥

지옥은 지하 1층에서 시작해 지하 100층까지 내려간다. 입장 전 HP·MP와 관계없이 입장 시 모두 100%로 시작하며, 탐험 중에는 남은 HP·MP가 다음 전투로 이어진다. 지옥 열쇠·화려한 지옥 열쇠·찬란한 지옥 열쇠 중 선택한 열쇠 1개를 소비하며 낙하 횟수는 각각 5·6·7회다. 전투 승리 후 좌우 중 한쪽으로 낙하하면 서버가 1~20층 이동을 추첨한다. 로켓 점프를 얻으면 다음 낙하는 16~20층이다. 100층을 넘어가는 이동은 100층에 도착한다.

권장 전투력은 `30000 * (1 + floor(현재층 / 10))`이다. 1~9층 3만, 10~19층 6만, 100층 33만이며 UI에서 수치를 나열하지 않는다. 첫 방은 일반 몬스터이고 이후 일반·엘리트·보스의 확률은 60%·30%·10%로 두었다. 100층은 보스다. 기존 필드 몬스터와 전투 엔진을 재사용한다. 천상의 증강·사건·뒤틀림·주간 기록은 지옥에 적용하지 않는다.

11·22·33·44·55·66·77·88·99층에 **도착하면** 전투 대신 제단이 나타난다. 지나친 층의 제단을 소급해서 사용하지 않는다. 제단은 한 번만 사용하며 일반 상자 추가 40%, 낙하 1회 추가 20%, 로켓 점프 20%, 풍요로운 상자 추가 20%다. 제단 사용을 해당 층 클리어로 기록한다. 마지막 낙하로 도착한 제단에서도 낙하 횟수를 얻으면 탐험을 계속한다.

낙하 횟수를 모두 사용한 뒤 도착층을 클리어하거나, 100층을 클리어하면 상자를 선택한다. 사망·포기도 **마지막 클리어 층**으로 상자를 지급한다. 클리어한 층이 없으면 보상 없이 종료한다. 사용한 열쇠는 돌려주지 않는다.

기본 후보는 3개이며, **개봉은 항상 1회**다. 제단의 상자 추가와 풍요로운 상자 추가는 **선택 후보만 1개씩** 늘린다. 풍요로운 상자 추가로 생긴 후보는 풍요로움이 확정이며 다른 후보는 각각 10% 확률이다. 후보 종류는 9종을 중복 없이 추첨하고 9개를 초과할 때 다시 종류를 채워 추첨한다. 종류 및 실제 내용물은 종료 시 한 번 확정해서 저장한다. 재접속이나 중복 요청으로 재추첨되지 않는다. 이전 규칙으로 저장된 탐험도 화면을 다시 불러오거나 동작을 요청할 때 개봉을 1회로 제한한다. 이미 상자를 개봉했다면 지급한 보상은 보존하고 추가 개봉 없이 종료한다.

보상 구간은 1~9층 최소 단계, 10~19층 1단계부터 90~99층 9단계, 100층 최고 단계다. 모든 개봉 상자에 상급 강화석 `10 * (단계 + 1)`개가 추가된다. 풍요로운 상자는 **상급 강화석만 3배**이며 다른 보상 수량은 같다. 운영 중 보상표는 `Paradise.hell.rewards`가 기준이고 탐험 입장 시 표를 저장한다.
