# 흑막 월드보스 칭호

- 대탐정 (greatDetective): 흑막 누적 실제 피해량 20,000,000. 장착 시 월드보스 전투 중 최종 공격력 +30%.
- 흑막 (blackCurtain): 흑막 스킬 선택 후 입장 확정 10회. 장착 시 월드보스 전투 중 회피 확률 +10%p.

기존 칭호 정의 파일 DB/RPGenius/titles.json에 두 항목만 추가했다. 진행도는 유저의 titleProgress.blackCurtainDamage 및 blackCurtainParticipations에 저장한다. 전투 입장이나 피해 처리에서 기존 칭호 해금 함수를 호출하며 도감에 조건과 진행도가 표시된다. 다른 보스 기록, 취소된 입장, 보스의 남은 체력을 초과하는 피해는 조건에 포함하지 않는다. 보스가 부활해도 유저의 누적 칭호 기록은 유지된다.

효과는 장착 중이고 field.worldBoss가 활성화된 실제 전투에서 적용한다. 스킬 선택 중, 일반 사냥, 필드를 제거한 PVP 스탯 계산에는 적용되지 않는다. 공격력은 기존 조건부 최종 공격력 처리 단계에서 1.3배, 회피는 기존 회피 스탯에 0.10을 가산한다. 기존 회피 불가 고정 피해 규칙은 변경하지 않는다.

과거 흑막 전체 누적 피해/참여 횟수는 기존 코드에서 기록하지 않았으므로 이번 코드 적용 이후부터 집계한다. 기존 유저나 운영 월드보스 데이터를 일괄 수정하지 않았다.

이미지: 현재 연결 버킷 eefl-image 전체 키에서 두 칭호 이미지를 찾지 못했다. 칭호 기본 경로 tcgenius/assets/ui/칭호/대탐정.png 및 흑막.png를 사용하도록 이름으로 연결되며, 실제 파일 업로드/다른 S3 경로 확인은 남아 있다. 새 그림은 생성하지 않았다.

기존 월드보스 반격 테스트에 새 칭호 해금 의존성과 피해 임계값·초과 피해·중복 해금 사례를 추가했다. 테스트 실행 및 배포는 하지 않았다.
