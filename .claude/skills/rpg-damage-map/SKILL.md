# RPGenius damage pipeline map

Load this before touching combat. Two engines: **solo** (`rpgenius.js`) and **party quest** (`partyquest.js`). They share data (Skills/Equipment/stats) but have SEPARATE damage code — changes usually need both. (`hunter_colosseum.js` is an unrelated legacy game; **H필드** = web front-end over the solo engine; **일일 던전** = a solo context.) Verify with `rpg-check`.

## SOLO (rpgenius.js)
**Player → monster** — single chokepoint `calculateAttackHitResult(rawDamage, defense, penetration, stats, slotEffects, extra, defenderStats)` (4 callers: `calculateMonsterAttackHitResult`, `buildEliteHuntResult`, `buildHuntResult`, `dealDamageToWorldBoss`). Per hit:
0. `extra.precalculatedDamage` → early-out (DoT ticks: no crit/def/element/variance). `hitCount = extra.hitCount || extra.comboHitCount || getComboHitCount(stats)`.
1. Per-attack-unit layer: `extra.perAttackUnitExtras[unit]` (numeric keys add onto `hitExtra`: `allElementAtk/waterAtk/critChanceBonus/critMulBonus/damageBonusMul/defReductionBonus/extraDamageBonus/finalDamageBonus/pntBonus/rainbowAttackRatio`), `extra.beforeAttackUnit(...)` callback, `hitStats` = stats + unit element adds.
2. `elementMul` computed now (`extra.attackElement` → `getElementDamageMultiplier`; **no element → `1 + stats.nonElementDamage`**), applied at step 9. 10th-attack bonus (`extra.tenthAtkStart/tenthAtkBonus`, 흠시원).
3. `baseDamage = rawDamage × (1 + damageBonusMul(+tenth)) × (1 + stats.finalDamage + hitExtra.finalDamageBonus)`; combo mods (`stats.comboCritMul/comboLastCrit/comboLastCritMul`).
4. Crit — `applyCriticalDamage(base, stats, hitExtra, defenderStats)`: chance `(stats.crit + critChanceBonus) × critChanceMul`, mul `stats.critMul + critMulBonus`, final `1 + (mul−1) × (1 − defender critDef)` (감소율; party uses the SAME formula since 2026-08-17); `forceCritical` / `disableCritical`. `stats.hasAbyssDoom` (passive 1) may append a hit on crit basics.
5. Defense — `stats.trueDamageChance` roll (운명, passive 0) → `getDamageAfterDestinyDefense` (def halved) else `getDamageAfterReducedDefense`; pen = `penetration + pntBonus`, reduction = `getTotalDefenseReductionRate(stats, slot) + defReductionBonus`. `stats.hasCelestia` (passive 2): +15% flat on skills.
6. Flat adds: `stats['000']`, `extra.skillTrueDmg`, `extra.oneTimeTrueDmg` (hit 0); `stats.comboDamage` on combo hits.
7. Variance `applyDamageVariance` (98–102%).
8. **Element multiplier** (`hitDamage × elementMul`) — "last" for the core, but a tail follows:
9. Post-element tail (each × its OWN element multiplier only, no double scaling — same order as party): `stats.critLightBonus/nonCritLightBonus` (×lightMul), `extra.bribeDarkBonus` (×darkMul), `extra.deepWaterBonus` (×waterMul, 심해의 모자), `stats.elementalExtraDamage` (element attacks only), `rainbowAttackRatio` (atk × ratio × elementMul), unit `extraDamageBonus`, `extra.afterAttackUnit(...)`, `extra.oneTimeFinalDamage` (hit 0).
10. Post-loop: `stats.extraDamage + extra.extraDamageBonus` on the **summed** total. `extra.disableEquipmentBonusDamage` gates 000/celestia/light/bribe/elemental/rainbow/extraDamage.
- Stat-driven (both engines, since 2026-08-17): `ultimateDamage` (+damageBonusMul on the user's ultimate = last skill), `ultimateCooldownFlat` (ms off the ultimate's cooldown), `lightFinalDamage` (명 attacks), `equipmentEffectCooldownFlat`/`equipmentEffectDurationFlat` (`equipmentCooldownMs`/`equipmentDurationMs`), `partyAllElementAtk` (party start, all members). `burnDamage`/`dotDamage` size DoT ticks only; `waldolandDmg` solo-only, `butagamePartyQuestDmg` party-only by design.

**Entry funnels**
- `applyFieldDamageAction(user, context, rawDamage, extra, actionType, skill)` — the manual chokepoint (3 callers: `useBasicAttackInField`, `executeMainCardSkillInField`, `executeSelfDestructInField`). Sets `extra.isSkill/isBasic`, `extra.attackElement = getAttackElement(user, skill|null)`, `combatTargetKey`, `comboHitCount/attackUnitCount`, card-slot per-attack effects (`nonElementFinalDamage`→`finalDamageBonus`, `tenthAtkBonus`), field buffs (`pntBuff`→`pntBonus`, `nextFinalDamageBonus`, 유서새김 mark→`defReductionBonus`), `applyDailyDungeonEffectToAttack`, then **`applyTranscendPreAttack(user, context, rawDamage, extra, actionType, skill)`** (초월 장비 pre-attack effects, 수나타 owner buff, 건력 atkBuff, per-attack-unit extras) → dispatch: hell pillar → `buildHellPillarResult` (flat 1 dmg, no chokepoint) / hell·elite → `buildEliteHuntResult(user, dungeon, rawDamage, extra)` / worldBoss → `applyWorldBossDamageAction(user, boss, rawDamage, extra, actionType, skill)` → `dealDamageToWorldBoss(user, boss, rawDamage, opts)` / else (normal + dailyDungeon) → `buildHuntResult(user, dungeon, rawDamage, extra)`.
- Skill effects set in `executeMainCardSkillInField` (basic in `useBasicAttackInField`); worldboss chosen skills (`ExtraSkills.json`) in `useWorldBossChosenSkill` → `dealDamageToWorldBoss` directly.
- **Timers** (all bypass `applyFieldDamageAction`, call build*/`dealDamageToWorldBoss` with `extra = {isBotAutoAttack, summonAttack, disableEquipmentBonusDamage, hitCount: 1, attackElement…}`; single-hit like party, `summonAttack` zeroes retaliation and skips attack-recovery/owner buffs, `isBotAutoAttack` skips action cooldown): `runFieldIktaeBotTick` (4s, `fieldIktaeBotTimers`), `runFieldSunataTick` (5s, `fieldSunataTimers`), `runFieldMarkTick` (유서새김 DoT 2s, `fieldMarkTimers`), `runFieldEquipmentDotTick` (burn/hellfire/심판/shadowQueue 200ms, `fieldEquipmentDotTimers`, `precalculatedDamage`+`dotAttack`).
- **Monster → player**: `calculateMonsterAttackHitResult(monster, defenderStats, slotEffects, extra)` — base = `atk × extra.receivedDamageMul × (1+takenDamage) × (1−slot.hpDamageReduction) × (1−extra.receivedDamageReduction)` (`receivedDamageReduction` = 건력/필드버프 + 피의 흐름 + 최후통첩 아머 from `applyTranscendPreAttack`), then recurses into `calculateAttackHitResult` with `{attackElement: monster.element}` (player resist applies; monster `pntPercent` is read from its stats — don't also pass it as slot `defReduction`). Callers roll player `avd`. Worldboss-skill→player: `runWorldBossSkillTick` — same mitigation set (avd, takenDamage, hpDamageReduction, 건력/버프, 피의 흐름, 최후통첩 아머, counter) then `getDamageAfterDefense` × boss element mul; `정권` ramp, karma stack, thorns, kill-recovery, immortal armor.

## PARTY (partyquest.js)
**Player → monster** — single chokepoint `calculateOutgoingDamage(attacker, monster, room, rawDamage, extra)` (9 callers: basic `computeBasicDamage`→`performBasicAttack`, main-card `executeMainCardSkillEffect`→`dealSkillDamageToMonster`, quest skills inline in `executeSkillEffect`, mob-phase `applyMobPhaseDamage`, iktae/sunata ticks, 자폭).
- Pre-loop: `preparePartyAttackUnits` (per-unit extras, early-return for summon/dot) → monster `avd` dodge → `contextMul` by monster type (`damageBonus`/`eliteDmg`/`bossDmg`) → transcend block (`bloodyShoesExtraDamage`, `blackEchoSkillDamage`, `manaAmplifierFinalAtk`, …) → `atkDefReduce` (5s party-wide monster def debuff) → `waldolandDmg`/`butagamePartyQuestDmg` → `contextMul ×= 1+damageBonusMul` → `extraFinalDamage` (finalDamageBonus + element-conditional buffs + `slotEffects.nonElementFinalDamage` + `runtime.nextFinalDamageBonus`).
- Per hit: unit extras/`partyBeforeAttackUnit` → `hitStats.allElementAtk += 킹메이커` → `resolvePartyAttackElement(attacker, hitExtra.skillElement)` → `elementMul` (or `1+nonElementDamage`) → `hitDamage = rawDamage × contextMul(+unit, ×10th) × (1 + finalDamage + extraFinalDamage) × dealtDmgMul × getFinalDamageMul(attacker)` → crit inline (`critMul − monster critDef`; `extra.extraOnCrit`/`hasAbyssDoom` extra hits) → `hasCelestia` → `× (1+monster takenDamage) × getMonsterTakenDmgMul` → defense (`trueDamageOnCrit`→`getFixedDamageAgainstMonster` / `trueDamageChance`→destiny / `getDamageAfterDefense`) → 000/skillTrueDmg → **element** (also scales fixed/destiny) → tail (light/dark/`deepWaterBonus`/elementalExtraDamage/comboDamage/rainbow/`partyAfterAttackUnit`) → **variance AFTER element** → `oneTimeFinalDamage`. Post-loop: attackCounter, 나인멘스 stacks, `extraDamage` on total; result `{damage, fixedDamage, destinyDamage, isCrit, hitCount, …, equipmentTriggerAllowed}`.
- `getFinalDamageMul(attacker, {summonAttack})` = 복수의 칼날 × 마력감응 × 수나타 buff × 건력 atkBuff (수나타/건력 skipped for summon attacks, like solo). Applied ONCE inside `calculateOutgoingDamage` — quest-skill `def.damage` must NOT pre-multiply it. Crit: same formula as solo (`1 + (critMul+bonuses−1) × (1−critDef)`); 별빛 = flat +15% of pre-defense damage added after defense (like solo); 포커 못 하시네 sets `separateBasicAttackHits` so its 9 hits count as 9 attacks for 나인멘스/10th-hit counters.
- `applyPlayerDamageToBoss(room, mon, attacker, dmg)` gates 흑화 호두 익스트림 (role-lock/curse) then **`applyBossHpDamage(room, mon, dmg)`** — the single HP-writing path (boss `shield` first, `hpFloor`, `bossState.onDamageTaken`). Reflect: `calculateNormalDamageToMonster` (가시 갑옷; no element).
- **`BOSS_HANDLERS`** = `{ '<monster.name>': { init(monDef)→bossState, onSpawn(room,mon), step(room,mon,dt) } }` (흑화 호두/타부자고/잉여왕); phase `type:'boss'` + matching name registers; `stepBoss` looks up `mon.bossKey || mon.name`. Toolkit: `registerHpGimmicks`, `startBossCast`, `startVote`, `startChatGimmick`, `applyBossGroggy`, `setBossShield`, `applyFixedDamageToMember`, `wipeParty`.
- **Monster → player**: `computeMonsterDamage(room, mon, target)` (multi-hit, returns `{damage, mitigation}`; element via `mon.element` vs player resist) and `calculateNormalDamageToMember(room, mon, target, raw)`; boss %HP mechanics via `applyFixedDamageToMember`. All land in `applyDamageToMember(room, member, dmg, source)` (order: takenDamageUp → `dodgeNext` → `absorbAlly` → `nextDamageReduction` → `shield`/`shieldHits` → iktaeBot absorb → HP → thorns → death).
- **Summons**: `stepRoom` member loop (`r.iktaeBot` 4s / `r.sunata` 5s `nextAttackAt`), tick `TICK_MS = 200`; `INTRO_GRACE_MS`/`room.introUntil` freezes `stepRoom`.
- Stats are a **snapshot**: `member.baseSnapshot = { stats, slotEffects, mainCardSkills, immortalArmor, manaResonance, thorns, elementChain, transcendEquipment }` (from `calculateUserStats` etc. at room start; passives 3/4/5 detected via `rpgenius.getEquippedPassiveIds` — 7 slots + `isEquipmentEffectActive`, same as solo). Clear rewards apply the same exp/gold multipliers as solo hunts (slot exp/gold %, stats exp/gold, potions, prestige, low-level ×1.5). Live tweaks on `member.runtime.*` (`hp/hpMax/mp/mpMax/shield/shieldHits/shieldExpireAt/atkBuff/takenDmgMul/nextBasicDamageBonus/nextSkillDamageBonus/nextDamageReduction/nextFinalDamageBonus/critBoostNext/trueDamageOnCritNext/dodgeNext/absorbAlly/pntBonusValue/pntBonusUntil/gunryeok/sivalonCharge/sunata/iktaeBot/dots/stackCounters/attackCounter/equipmentState/buffs…`).

## extra.* hooks
- **Shared** (both engines): `damageBonusMul`, `finalDamageBonus`, `extraDamageBonus`, `forceCritical`, `disableCritical`, `critChanceBonus`, `critChanceMul`, `critMulBonus`, `pnt`, `pntBonus`, `defReductionBonus`, `hitCount`, `comboHitCount`, `attackUnitCount`, `perAttackUnitExtras`, `skillTrueDmg`, `oneTimeFinalDamage`, `bribeDarkBonus`, `shadowDamageRate`, `lifeStealFromPreMitigation`, `isSkill`, `isBasic`, `summonAttack`, `dotAttack`, `disableEquipmentBonusDamage`.
- **Solo only**: `attackElement`, `receivedDamageMul`, `receivedDamageReduction`, `basicAttackSkill`, `goldBonus`, `shieldNotice`, `precalculatedDamage`, `oneTimeTrueDmg`, `tenthAtkBonus/tenthAtkStart`, `buildNmmStack`, `combatTargetKey`, `separateBasicAttackHits`, `beforeAttackUnit/afterAttackUnit`, `isBotAutoAttack`, `trueDamage` (worldboss thorns), display: `notice/mpCost/mpAfter/maxMp`, `skillHpRecovery/skillMpRecovery/skillRecoveryChance/skillRecoveryAmount`, `user.field.shield`, `getFieldBuffs(user)` keys (`nextBasicDamageBonus`, `nextSkillDamageBonus`, `nextDamageReduction`, `receivedDamageReduction`, `receivedDamageMultiplier`, `nextFinalDamageBonus`, `pntBuff`, `actionCooldownReduction`, `counterReady`), `user.field.{sunata,iktaeBot,gunryeok,sivalon,sivalonCharge,mark,nmmStacks,attackCount,karmaStack,equipmentState}`.
- **Party only**: `skillElement`, `skillName`, `extraOnCrit`, `partyMpFlat`, `trueDamageOnCrit`, `deepWaterBonus`, `partyBeforeAttackUnit/partyAfterAttackUnit`, `previewNextBefore`; `caster.runtime.*` (above), `upsertMemberBuff(member, {id,label,value,remain})`.

## Element (see [[element-system]])
4 elements (`ELEMENT_ATK_KEYS`/`ELEMENT_RES_KEYS`: 화/수/명/암) + `allElementAtk`/`allElementRes` folded into every element. Multiplier `max(0, 1 + (강화+all − 저항+all) × 0.001)`. Attacker element = `getAttackElement`: weapon (weapon **orb element overrides**) > skill `element` > `rest` (support > hat > armor > pants > shoes > accessory). No element → `nonElementDamage` takes the multiplier slot; `elementalExtraDamage` applies after (element attacks only). Party: `resolvePartyAttackElement` uses `baseSnapshot.elementChain`. Monster resist = numeric `stat.fireRes` etc.; monster attack type = top-level `element` (string).

## Concurrency
Solo timer ticks join the user's command queue via `enqueueFieldTick(userName, fn)` → `enqueueUserCommand(fieldQueueKeys[name]||name, fn)`; web/H필드 actions use `enqueueFieldAction(user, fn)` (queue `'account:'+user.id`, registers `fieldQueueKeys[user.name]`) — no load-modify-save races with manual attacks. Party combat is synchronous in-memory room state → atomic vs the 200ms `stepRoom` tick.
